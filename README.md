# 🤖 AutoNews Agent — نظام الأتمتة الإخبارية الذكي متعدد المنصّات

نظام Python مستقل وموجّه ذاتياً يبني **شبكة إعلامية تُدار بالذكاء الاصطناعي**: يسحب الأخبار دورياً من مصادر RSS، يعيد صياغتها بأسلوب مخصّص لكل منصّة، ثم ينشرها تلقائياً على **تيليجرام، فيسبوك، وX** — دون أي تدخّل يدوي، ودون سيرفر دائم (GitHub Actions).

```
   ┌──────────┐   ┌───────────┐   ┌──────────────────────┐   ┌──────────────┐
   │  RSS/Atom │ → │ تصفية     │ → │  Gemini + نظام       │ → │ تيليجرام     │
   │ 10 مصادر  │   │ تكرار/حداثة│   │  تبديل 5 مفاتيح     │   │ فيسبوك       │
   └──────────┘   └───────────┘   │  × 6 نماذج           │   │ X            │
                                  └──────────────────────┘   └──────────────┘
                                          ↑ مع توجيه ذكي حسب المصدر/الوسم/الكلمة
```

## 📌 المميزات

| الميزة | التفاصيل |
|---|---|
| 🛡️ **حصانة ضد انتهاء الحصص** | 5 مفاتيح × 6 نماذج = **30 زوجاً**، تبديل تلقائي في أجزاء من الثانية عند أي `429/403/404/5xx` |
| 🧠 **صحة المفاتيح محفوظة** | المفتاح المستنفَد/المعطوب يُجمّد ويُحفظ بين التشغيلات (`state/ai_health.json`) فلا يُجرَّب عبثاً |

## 🚀 التشغيل السريع (5 دقائق)

### 1) محلياً — معاينة بلا أي توكنات

```bash
cd autonews-agent
python -m pip install -r requirements.txt
cp .env.example .env          # اختياري الآن

# معاينة كاملة بلا AI وبلا نشر (تطبع المنشورات في الطرفية)
PYTHONPATH=src DRY_RUN=true AI_DISABLED=true python -m autonews.main --limit 3
```

لعرض المحتوى فعلياً في الطرفية بدل إرساله، فعّل قناة المعاينة:

```bash
# في config/channels.yml  →  console_preview  →  enabled: true
PYTHONPATH=src AI_DISABLED=true python -m autonews.main --limit 2
```

### 2) فحص الصحة قبل أي نشر

```bash
PYTHONPATH=src python -m autonews.main --check
```

يطبع جدولاً بكل قناة: هل توكناتها موجودة؟ ما مصادرها؟ كم مفتاحاً ونموذجاً جاهزاً؟

### 3) تجربة نظام التبديل التلقائي (بلا مفاتيح حقيقية)

```bash
python examples/demo_failover.py
```

يحاكي: المفتاح الأول انتهت حصته → الثاني معطوب → الثالث ينجح، ويعرض جدول صحّة المفاتيح.

### 4) الاختبارات وفحص المفاتيح

```bash
PYTHONPATH=src python -m pytest              # 286 اختباراً بلا شبكة
PYTHONPATH=src python -m autonews.main --check --probe   # فحص كل مفتاح Gemini فعلياً
```

`--probe` يجيب على السؤال العملي: **أي مفتاح من الخمسة يعمل الآن؟** ويُظهر رمز الحالة لكل مفتاح بالمللي ثانية.

## 🔐 إعداد الأسرار (GitHub Secrets)

اذهب إلى: `Settings → Secrets and variables → Actions → New repository secret`

| الاسم | إلزامي | الوصف |
|---|---|---|
| `GEMINI_API_KEYS` | ✅ | المفاتيح مفصولة بفواصل: `k1,k2,k3,k4,k5` — أو استخدم `GEMINI_API_KEY_1…5` |
| `GEMINI_MODELS` | ❌ | تجاوز قائمة النماذج، مثل `gemini-2.5-flash,gemini-1.5-pro` |
| `TELEGRAM_BOT_TOKEN` | ✅ | من [@BotFather](https://t.me/BotFather) — ويجب إضافة البوت **مشرفاً** في القناة |
| `TELEGRAM_CHAT_ID` | ✅ | `@my_channel` أو `-1001234567890` |
| `TELEGRAM_TECH_CHAT_ID` | ❌ | لقناة التقنية (إن فعّلتها) |
| `FACEBOOK_PAGE_ID` | ✅ | معرّف الصفحة (About → Page ID) |
| `FACEBOOK_PAGE_TOKEN` | ⭐ | توكن صفحة طويل الأمد (الأفضل) |
| `FACEBOOK_USER_TOKEN` | ⭐ | بديل: يُستخرج توكن الصفحة تلقائياً |
| `X_API_KEY` / `X_API_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_SECRET` | ✅ | OAuth 1.0a مع صلاحية **Read and Write** |
| `X_BEARER_TOKEN` | ❌ | بديل OAuth 2.0 user-context |
| `ALERT_BOT_TOKEN` | ⭐ | بوت التنبيهات (افتراضياً نفس البوت) |
| `ALERT_CHAT_ID` | ⭐ | دردشة إدارية خاصة للتنبيهات والمسوّدات |

> ⭐ فيسبوك: يكفي **أحد** التوكنين (`PAGE_TOKEN` أو `USER_TOKEN`).

### كيف أحصل على مفاتيح Gemini المتعددة؟
1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → **Create API key**.
2. كرّر العملية بحسابات Google مختلفة (مفتاح واحد يخصّ مشروعاً واحداً، وحصته محدودة).
3. اجمعها في سرّ واحد: `GEMINI_API_KEYS = key1,key2,key3,key4,key5`.

### 💾 أين تُحفظ الحالة؟ (مهم للاستمرارية)

| الطريقة | المشكلة | الحل المعتمد |
|---|---|---|
| ❌ `actions/cache` | يُحذف بعد **٧ أيام** بلا استخدام ⇒ النظام ينسى ما نشره ويُكرّره | — |
| ❌ كاش بمفتاح `run_id` | المسار السريع والدورة العادية **لا يريان حالة بعضهما** | — |
| ✅ **commit داخل المستودع** | ينتفخ الملف قليلاً | `scripts/save_state.sh` + ضغط العناوين (**−٥٦٪**) |

كل تشغيل يدفع `state/` و `logs/` مع `[skip ci]` (لا يُشغّل الاختبارات).
الحجم الفعلي: **~٢ KB**، وأسوأ حالة بعد ٤٠٠٠ مقال: **<٦٠٠ KB**.

### جدولة التشغيل
في `.github/workflows/autonews.yml`:

```yaml
on:
  schedule:
    - cron: "0 */2 * * *"   # كل ساعتين (UTC) = كل ساعتين بتوقيت بغداد +3
```

قدّم أول تشغيل يدوياً: `Actions → 🤖 AutoNews Agent → Run workflow` مع تفعيل `dry_run` أولاً للتأكد.

## 🛡️ كيف يعمل نظام الحصانة بالتفصيل؟

المصنوفة هي **مفتاح × نموذج**، والأزواج مرتّبة: أفضل نموذج مع كل المفاتيح أولاً، ثم النموذج التالي — حتى لا تنهار جودة المحتوى بسبب مفتاح واحد.

| نوع الخطأ | المُسبّب | رد الفعل |
|---|---|---|
| `QuotaError` | `429 RESOURCE_EXHAUSTED` | تجميد **الزوج** 15 دقيقة → الزوج التالي فوراً |
| `AuthError` | `400 API_KEY_INVALID` / `401/403` | عزل **المفتاح كله** 24 ساعة (كل النماذج) |
| `ModelError` | `404` / نموذج غير مدعوم | تجميد **النموذج** 12 ساعة (كل المفاتيح) |
| `TransientError` | `5xx` / مهلة / شبكة | إعادة محاولة واحدة بتراجع أُسّي → ثم تجميد دقيقة |
| `NonRetryableError` | حجب سلامة المحتوى | لا تبديل — يُستخدم القالب الاحتياطي |
| الكل مستنفَد | — | `AIUnavailable` → **قالب احتياطي بلا AI** والتشغيل يكمل بنجاح |

مثال من سجلّ حقيقي (عرض تجريبي):

```
⏳ حصة منتهية | AIzaSy…0001/gemini-2.5-flash → تجميد 917s
🔒 مفتاح غير صالح | AIzaSy…0002 → عزل المفتاح كلياً
✅ توليد ناجح | key#3/gemini-2.5-flash | محاولات=3 | زمن=0.0s
```

> الحصص المجانية من Gemini تُحسب **لكل مشروع/مفتاح**، لذا 5 مفاتيح = 5 أضعاف الطاقة. ومع تبديل النماذج يبقى البوت يعمل 24/7.

## 🔔 الميزات التشغيلية بالتفصيل

### 1) التنبيهات — أهم ميزة (لأن الصمت هو العدو)
```
TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID   ← الافتراضي
ALERT_BOT_TOKEN   / ALERT_CHAT_ID       ← اختياري: بوت/دردشة إدارية منفصلة
```
يُرسل تنبيه في الحالات: فشل تشغيل · استنفاد كل مفاتيح Gemini · **تشغيلان متتاليان بلا نشر** · تعطيل مصدر.

> استخدم دردشة إدارية **منفصلة** عن قنوات النشر (`ALERT_CHAT_ID`) كي لا يرى المتابعون رسائل التشغيل.

### 2) بوّابة الجودة — منع الاختلاق
النماذج تختلق أرقاماً (نسب/أعداد). البوّابة تستخرج كل رقم من المنشور وتتحقّق من وجوده في الخبر الأصلي:

```
🚧 رُفض منشور (tg_main): أرقام غير موجودة في المصدر: 450
```
كما ترفض: عنواناً مضلّلاً كلياً · حقن تعليمات (`تجاهل ما سبق`) · نصّاً قصيراً جداً · تكلّم النموذج عن نفسه.
تستثني تلقائياً أرقام الروابط والتوقيت النسبي («قبل 14 دقيقة») لتجنّب الرفض الخاطئ.

### 3) صور الأخبار
تقرأ `og:image` من صفحة الخبر، تتحقّق من نوع الصورة فعلياً (magic bytes لا الامتداد)، وتتجاهل الشعارات والصور الصغيرة. تيليجرام: `sendPhoto` + بقية النص رسالة؛ فيسبوك: `/photos`؛ X: `media/upload` ثم التغريدة.

### 4) المراجعة البشرية (اختيارية)
```yaml
# config/settings.yml
review:
  enabled: true          # أو متغيّر البيئة REQUIRE_REVIEW=true
```
تصلك مسوّدة في تيليجرام مع زرّي **✅ نشر / ❌ تجاهل**. التشغيل التالي يقرأ قرارك (`getUpdates`) وينشر المقبول فقط. المسوّدة غير المبتوت فيها تُلغى بعد `timeout_hours`.

### 5) الأخبار العاجلة
`breaking.keywords` + حداثة (≤ ساعتين) ⇒ الخبر يُرتَّب أولاً، ويحصل على `🔴 عاجل`، ويمكنه تجاوز `max_posts_per_run` بقناة `breaking_boost: true` حتى `max_per_run`.

### 5.5) ⚡ النشر الفوري (Fast Lane) — الأهم للتنافس

**المشكلة**: الدورة كل ساعتين تعني أن خبر الحرب قد يُنشر بعد 120 دقيقة. قناة «مباشر» تنشره في 30 ثانية.

**الحل**: مسار **منفصل ومستقل** يفحص فقط «هل ظهر عاجل جديد؟» وينشر فوراً.

```bash
python -m autonews.flash_main                 # دورة سريعة واحدة (~17ث)
python -m autonews.flash_main --interval 30   # مستمر كل 30 ثانية (VPS/Docker) ⭐ الأسرع
```

**ما يُصنَّف عاجلاً** (بأوزان، لا مجرد كلمات):

| الفئة | أمثلة | الدرجة |
|---|---|---|
| ⚔️ `war` | قصف · غارة · صاروخ · انفجار · اشتباكات · قتلى · حصيلة | 15–25 |
| 🚨 `disaster` | زلزال · فيضان · سيول · حريق · انهيار | 15+ |
| 📅 `holiday` | عطلة · تمديد · تعطيل · دوام · مناسبة | 20+ |
| ❗ `major` | استقالة · إقالة · اعتقال · إغلاق · سعر الصرف · الرواتب | 8–15 |

**الضمانات الثلاثة (حتى لا يتحوّل إلى فيضان):**
1. **حارس الحداثة**: لا نشر فوري لخبر > 45 دقيقة (يظهر في السجل: `⏳ عاجل لكن غير طازج (69 دقيقة)`).
2. **سقف الساعة**: 6 أخبار/ساعة لكل قناة + فاصل 25 ثانية بينها.
3. **حارس المحتوى**: «بالفيديو/شاهد/تحليل/حوار» لا يُصنَّف عاجلاً.

**مطابقة عربية واعية**: كلمة «عيد» لا تُطابق «تصعيد»، و«عطلة» تُطابق «العطلة» و«بالعطلة».

#### 📊 جدول التأخير الواقعي (كن صريحاً مع نفسك)

| طريقة التشغيل | التأخير الفعلي | الجهد | الحكم |
|---|---|---|---|
| GitHub Actions فقط (كل ساعتين) | 120 دقيقة | صفر | ❌ لا تُنافس |
| **+ مسار فلاش كل 5 دقائق** | **5–20 دقيقة** | صفر (مجاني) | ✅ منافس جيد |
| VPS 2$ شهرياً (`--interval 30`) | **30–90 ثانية** | بسيط | ✅✅ منافس حقيقي |
| Push-to-Channel (يدوي من الجوال) | **ثوانٍ** | نقرتان | ✅✅✅ الأسرع بشرياً |

> ⚠️ **حقيقة تقنية**: GitHub يرفض جدولة أقل من 5 دقائق، ويؤخّر التشغيل عند الازدحام. **لا يمكن** الحصول على «ثوانٍ» من GitHub Actions وحده — هذه ليست حدوداً في الكود بل في المنصّة. الحلّان أعلاه (VPS أو Push-to-Channel) يحلّانها فعلياً.

#### 📲 Push-to-Channel — نشر فوري من جوالك
1. أنشئ قناة تيليجرام **خاصة** (غير عامة) مثل `AutoNews Urgent Scoped`.
2. أضف بوتك **مشرفاً** فيها.
3. أضف سرّاً: `TELEGRAM_SCOPED_CHAT_ID` = معرّفها.
4. أي رسالة تنشرها هناك تخرج فوراً على قنواتك الرسمية (تيليجرام/فيسبوك/X) بصياغة كاملة + صورة.

هذا يحلّ الحالة الأصعب: **حدث كبير وأنت بعيد عن الحاسوب**.

### 5.6) 📋 وضع «النتائج» (Outcome Mode) — لا تنشر الحادثة، انشر ما آلت إليه

**القاعدة التحريرية**: الحادثة الخام ليست خبراً. «انفجار في سوق» بلا حصيلة ولا قرار
هي **مادة خام**؛ ما يهمّ الناس: **شنو صار للشخص؟** و**شنو المحافظات المشمولة؟**

```yaml
# config/settings.yml
outcomes:
  enabled: true
  policy: outcomes_only      # outcomes_only | hybrid | raw
  allow_incident_headlines: false
  governorate_matrix: true
  min_outcome_chars: 60
```

| السياسة | السلوك |
|---|---|
| `outcomes_only` (الافتراضي) | أي حادثة بلا نتائج ⇒ **تُؤجَّل** ولا تُنشر (تظهر في السجل: `⏭ حدث خام بلا نتائج`) |
| `hybrid` | النتائج + الحوادث الكبرى فقط عبر `ESCALATION_SIGNALS` (عشرات القتلى، إخلاء، حالة طوارئ) |
| `raw` | السلوك القديم (كل خبر يُنشر) |

**إشارات النتيجة المرصودة** (وجود أحدها = يُنشر):
- 👤 **شخص**: حالة · توقيف · إفراج · إحالة · تعويض · حكم · اعتذار · استقالة · إقالة
- 🏛 **خدمة/قرار**: تعطيل · استئناف · فتح · إغلاق · صرف · توزيع · إعادة
- 🗺 **مصفوفة محافظات**: «العطلة في جميع المحافظات عدا أربيل ودهوك»
- 🔢 **أرقام حصيلة**: «5 وفيات و23 مصاباً» (يدعم الأرقام الهندية ٥/٢٣)

**المصفوفة المحافظاتية** (`outcomes.py`): 20 محافظة مع كل الأسماء البديلة
(الموصل→نينوى، الناصرية→ذي قار، الحلة→بابل، أسماء كردية)، ونافذة 70 حرفاً
قبل اسم المحافظة تحدّد: **مشمولة** أم **مستثناة** (استثنى/عدا/باستثناء/لم تشمل).

> **الاستثناء يغلب الإدراج**: في «العطلة غداً في جميع المحافظات عدا أربيل ودهوك»
> النتيجة: `مشمولة:الكل · مستثناة:أربيل،دهوك` — وليس العكس.

**الرفض الحاسم**: عبارات مثل «لم يُعلن عن إصابات» أو «لا معلومات حتى الآن عن الضحايا»
تُلغي أي إشارة نتيجة ⇒ **تأجيل**، حتى لو وردت كلمة «إصابات» في النص.

**الشكل النهائي** (يُبنى بقاعدة ثابتة لا بالذكاء الاصطناعي وحده):
```
📋 {ما آلت إليه الأمور في سطر}
━━━━━━━━━━━━━━
🗺 المشمولة: ...
⚪ المستثناة: ...
👤 الأثر على الناس: ...
```

**المصادر المرصودة** (27 مصدراً · 22 مفعّلاً · **6 رسمية**):

| المصدر | النوع | الثقة | ملاحظة |
|---|---|---|---|
| واع — محلي/سياسي/دولي (رسمي) | RSS | 1.3 | ⚠️ `/rss.xml` الجذري **متجمّد**؛ الأقسام `/ar/<sec>/rss.xml` هي الحيّة |
| شفق نيوز | RSS | 1.0 | الأسرع في العطل |
| بغداد اليوم | RSS | 0.9 | |
| المدى | RSS | 0.9 | |
| ألترا عراق | RSS | 0.85 | |
| Google News — عاجل العراق | RSS | 0.7 | `when:1d` **إجباري** وإلا يعيد أخباراً عمرها أشهر |
| Google News — عطلة رسمية | RSS | 0.75 | `when:7d` |
| USGS زلازل 4.5+ (رسمي) | Atom | 1.2 | |
| خلية الإعلام الأمني (رسمي) | Google News | 1.25 | `when:1d` — بيان أمني رسمي |
| قرارات حكومية (رسمي) | Google News | 1.2 | `when:1d` — مجلس الوزراء |

المصدر الرسمي يأخذ **+0.5 وزن ثقة** في التوجيه، فيتجاوز الوسيط عند التعارض.

### 5.7) 🧩 مميزات النتائج المتقدّمة (v6) — الثمانية التي اخترتها

فوق كاشف النتائج، ثمانية مكوّنات تعمل معاً (كلها في `src/autonews/outcome_features.py`):

| # | الميزة | ما تفعله | أين |
|---|---|---|---|
| ١ | 👉 **سطر «الأثر عليك»** | كل بطاقة تنتهي بجملة تخصّ القارئ لا الدولة: «دوامك الرسمي يتأثر — تحقّق من محافظتك» | `impact_line()` |
| ٢ | 🔄 **متابعة التطوّر** | الحادثة المؤجّلة تُسجَّل؛ وعند صدور نتيجتها تُنشر بوسم «🔄 تطوّر بعد ٥ ساعة» | `register_deferred()` · `resolve_followups()` |
| ٣ | 🗺️ **خريطة المحافظات** | منشور يومي واحد: من عطّل الدوام، من لم يعطّل، والخدمات المتأثرة | `build_governorate_daily()` |
| ٥ | ✅ **التحقّق المزدوج** | لا نتيجة بلا **مصدر رسمي** أو **مصدرين مستقلّين** (قاتل الشائعات) | `verify_result()` |
| ٦ | 🔍 **شفافية المصدر** | سطر أسفل كل بطاقة: المصدر + وزن الثقة + عمر الخبر | `source_line()` |
| ٧ | 🕵️ **الحوادث الصامتة** | حادثة كبرى بلا نتائج بعد ٦ ساعات ⇒ **تنبيه لك على تيليجرام فقط** (لا نشر) | `silent_incidents()` |
| ٨ | ⚖️ **تفاوت المحافظات** | «البصرة عطّلت وبغداد لا» يصبح خبراً مستقلاً يستحق النشر | `governorate_contrast()` |

**شرط «الأثر»**: القواعد مرتّبة بالأولوية (الدوام ← الرواتب ← سعر الصرف ← الطرق ← الماء/الكهرباء ← الأمن ← الصحة)، والقاعدة الأولى المطابقة هي التي تُطبع. بلا مطابقة ⇒ لا سطر (لا حشو).

**شرط «المتابعة»**: الحادثة تُطابق نتيجتها بـ**تشابه عنوان ≥ 45% أو محافظة مشتركة**، وتُزال من قائمة الانتظار لحظة النشر. سقف `followup_max_items: 60` يحفظ حجم ملف الحالة.

```yaml
outcomes:
  policy: hybrid            # النتائج دائماً + الحدث الكبير فقط
  impact_line: true
  followup: true
  followup_min_hours: 1.0
  daily_matrix: true
  daily_matrix_hour: 20     # ٨ مساءً بتوقيت بغداد
  contrast: true
  dual_verify: false        # اجعلها true إذا أردت منع أي خبر بلا مصدر رسمي
  source_line: true
  silent_enabled: true
  silent_hours: 6.0
```

#### 🔗 التكامل بين الطبقات (v6.1) — الفراغات التي أُغلقت

الميزات وحدها لا تكفي؛ الخطر في **الحدود بينها**. هذه سبع فجوات كانت حقيقية وأُصلحت:

| # | الفجوة | لماذا خطيرة | الإصلاح |
|---|---|---|---|
| ١ | الحوادث المؤجّلة **لا تُحذف أبداً** | ملف الحالة ينتفخ، والتنبيهات تصير ضجيجاً يومياً | `prune_incidents(72س)` تعمل أول كل دورة |
| ٢ | نفس الخبر بلغتين = **نشر مزدوج** | BBC إنجليزي + الجزيرة عربي ⇒ منشوران بعد التعريب | `is_already_covered()` يرفض الأصل قبل صرف حصة AI |
| ٣ | ٣ تنبيهات متفرّقة | التنبيهات المتكرّرة تُهمَل ⇒ لا أحد يقرأها | `notifier.digest()` رسالة **واحدة** بأقسام |
| ٤ | التقرير **لا يعرف** النتائج | لا تعرف هل النظام يعمل أم صامت | ٤ صفوف جديدة: نتائج · مؤجّل · تطوّرات · تعريب |
| ٥ | المصادر الرسمية تُسحب **بعد** غيرها | تنفد ميزانية السحب قبل الأهمّ | الرسمي أولاً (`official` ثم `trust`) |
| ٦ | `--check` لا يفحص الطبقات الجديدة | تكتشف الخلل بعد أسبوع صمت | قسم «🧩 تكامل الطبقات» + قراءة حالة حيّة |
| ٧ | مفتاح محروق يجرّبه الفلاش ثانية | ثوانٍ ضائعة في **أهم** لحظة | إذا كانت كل الأزواج مجمّدة ⇒ قالب فوري بلا انتظار |

**درس التصميم**: في نظام سريع، الفشل الصامت أخطر من الفشل الظاهر. كل فجوة أعلاه كانت
ستبدو «طبيعية» في السجلّ، لكنها تُفقدك إما خبراً أو ثقة.

#### 🌐 تعريب المصادر الأجنبية (`src/autonews/i18n/`)

مصدران إنجليزيان مفعّلان (BBC World · Google News Iraq EN) + سقف ٥ تعريبات لكل دورة حفظاً لحصة Gemini.

| الحماية | التفصيل |
|---|---|
| 🔢 **حفظ الأرقام** | إن اختلفت الأرقام الجوهرية عن الأصل ⇒ **يُرفض التعريب** ويبقى الأصل (لا نشر رقم مختلق) |
| 🈶 **فحص العربية** | مخرجات بلا حروف عربية كافية ⇒ رفض |
| 🪪 **الاسم الأصلي** | يبقى بين قوسين أول مرة (اختياري) |
| 🧯 **فشل آمن** | بلا مفاتيح AI ⇒ لا تعريب ولا اختلاق — الخبر يُترك كما هو |

**درس تقني**: `parse_dt` كان يفشل مع ISO يحمل أجزاء الثانية (`...T04:42:34.734885+00:00`)
⇒ صار يستخدم `datetime.fromisoformat` أولاً. هذا كان سيُعطّل «الحوادث الصامتة» بصمت.

### 6) العطل الرسمية: «تكرار أم تحديث؟» — أهم منطق تحريري
المشكلة الحقيقية: **العطلة تُعلَن اليوم وتُمدَّد غداً**. النظام القديم كان يحجب «تمديد العطلة»
لأنه يشبه «عطلة رسمية» — وهذا خطأ.

المنطق الجديد في `src/autonews/occasions.py`:

| الحالة | القرار |
|---|---|
| نفس العنوان حرفياً خلال **< 3 ساعات** (من مصدر آخر) | 🔴 تكرار ⇒ حجب |
| تشابه موضوعي + إشارة تحديث (**تمديد/تفاصيل/حصيلة/إلغاء/استئناف**) | 🟢 **تحديث يُنشر** بشارة `🔄 تحديث` |
| داخل مناسبة/موسم، خبر سابق أقدم من 3 ساعات، والموضوع عطلة/دوام/رسمي | 🟢 **تحديث يُنشر** |
| خبر مطابق بعد **> 6 ساعات** خارج المناسبات | 🟢 تطوّر طبيعي ⇒ يُنشر |
| موضوع مختلف | 🟢 يُنشر |

كما يقرأ **الكلمات الوظيفية** بدقّة: تشابه «عطلة رسمية يوم الخميس» و«تمديد العطلة الرسمية»
يُحسب **موضوعياً** (بعد إزالة «ال» واختلاف الصيغ الصرفية) لا حرفياً.

> 🔔 خلال المناسبة يرفع النظام أولوية الأخبار **الخدمية** (دوام، أسعار، خدمات، مواقيت) لأنها ما يبحث عنه الناس فعلاً.

### 8) التصفّح الآلي (Crawling)
| المشكلة الواقعية | الحل في الكود |
|---|---|
| رابط RSS مات (404) | **اكتشاف تلقائي**: `/feed`, `/rss.xml`, `<link rel=alternate>`, روابط RSS في الصفحة |
| موقع يحجب البوت (403) | **تدرّج هويّات**: بوت مهذّب ← متصفّح كامل، ثم توقّف ذكي (لا محاولات عبثية) |
| نص عربي مشوّه | **فكّ ترميز متدرّج**: المُعلن ← UTF-8 ← `windows-1256` مع فحص معقولية |
| خلاصة بعنوان فقط | **استكمال المتن** من صفحة الخبر: JSON-LD ← Open Graph ← Readability خفيف |
| بطء/تجاوز مهلة Actions | **ميزانية سحب**: 240 ثانية + حدّ صفحتين لكل مصدر (89ث ← 17ث) |
| ضغط gzip/deflate | فكّ ضغط تلقائي + تحويلات + `Retry-After` |

### 9) الكتابة المحفّزة (لا مملة)
المشكلة: «أعلن السيد المدير العام يوم أمس خلال مؤتمر صحفي أن…» — القارئ يمرّ فوراً.

**البنية المعتمدة: Hook → Value → Detail → Action**
```
❌ قبل: جدير بالذكر أن الأمانة العامة أعلنت، وعلى صعيد متصل، عن تمديد العطلة الرسمية…
✅ بعد: 🔄 تحديث | تمديد العطلة ليشمل الأحد

الدوام يعود الأحد في المواعيد المعتادة، باستثناء الدوائر الخدمية والصحية.

💡 الطلبة والمعلمون يشملهم التمديد
#العراق #عطلة
```
قواعد مُطبَّقة في `polish_body()` و`prompts.py`:
- العنوان يبدأ بالأثر/الرقم، لا بأسماء المسؤولين ولا «أعلن/صرّح».
- حذف **العبارات الميتة** آلياً: «جدير بالذكر» · «على صعيد متصل» · «في سياق متصل» · «هل تعلم»…
- تقسيم الجمل الطويلة: أي جملة > 26 كلمة تُقسَّم إلى أسطر.
- منع تكرار العنوان في أول الجسم.
- سؤال تفاعل واحد لفيسبوك/X فقط، ولا شيء في تيليجرام.
- 1–3 إيموجي في مواضع معنى، لا في كل سطر.
- سطر `💡 لماذا يهمّك؟` عند وجود قيمة حقيقية للقارئ.

## 📡 نموذج القنوات — قناة لكل قطاع (مع فصل حقيقي)

**السؤال الصحيح**: هل تحتاج قناة لكل قطاع؟ **نعم — لكن ليس من البداية.**

### نموذج التوصية

| المرحلة | القنوات | السبب |
|---|---|---|
| **البداية** | `tg_main` واحدة | تقسيم القنوات قبل وجود جمهور = صمت في كل قناة |
| **عند ٥٠٠+ متابع** | `tg_main` + `tg_anime` | الجمهور يطلب التخصّص، والأنمي لا يزعج قارئ الأخبار |
| **عند متخصّصين** | + `tg_sports` · `tg_tech` · `tg_econ` | كل جمهور في مكانه |

> ✅ **السبع قنوات جاهزة في `config/channels.yml` الآن** (`enabled: true`، لكل واحدة سرّها
> ووسومها وأسلوبها) — لا حاجة لإضافتها لاحقاً. غير المربوط يبقى صامتاً حتى تربطه من البوت،
> فتفعيله لا يكلّفك شيئاً وتأجيله لا يكلّفك شيئاً.

> **القاعدة**: القناة تُفتح حين يكون للقطاع **٣+ أخبار يومياً**. أقل من ذلك ⇒ منشور متفرّق
> لا يبني عادة متابعة، وأفضل مكانه القناة العامة.

### كيف يعمل الفصل؟ (`exclude_tags`)

```yaml
  - id: tg_main
    tags: []                        # عامة: كل شيء
    exclude_tags: ["أنمي"]          # 🚫 إلا الأنمي (له قناته)

  - id: tg_anime
    tags: ["أنمي"]                  # ✅ الأنمي فقط
    exclude_tags: []
```

| الخبر | tg_main | tg_anime | tg_tech |
|---|---|---|---|
| «Shiba Inu Rooms أنمي جديد» | ⛔ مستثنى | ✅ يُنشر | ⛔ |
| «تعطيل الدوام في البصرة» | ✅ يُنشر | ⛔ | ⛔ |

**الاستثناء يغلب العموم**: قناة عامة + `exclude_tags` ⇒ لا تستقبل القطاع إطلاقاً.

### أدوات الإدارة

```bash
# كل القنوات: مفعّلة؟ أيّها عام وأيّها متخصّص؟ ومن أين يأتي المعرّف؟

# فحص وصول البوت لكل قناة (حقيقي، عبر تيليجرام)
python -m autonews.channels_main --check
```

### 🎛 ربط المعرّفات من داخل البوت — بلا لمس أي ملف

**المشكلة القديمة**: لإضافة معرّف قناة كنت تحتاج حاسوباً + محرّر نصوص + تعديل `.env`.
**الحل**: بوت إعداد تفاعلي — **تضغط على القناة، يطلب منك المعرّف، ترسله، ينتهي**.

```
/start  →  لوحة الأزرار:
   ⬜ 📰 الأخبار العامة     ⬜ 🎬 الأنمي        ⬜ ⚽ الرياضة
   ⬜ 💻 التقنية            ⬜ 💰 الاقتصاد     ⬜ 🎮 الألعاب
   ⬜ 🗺️ المحافظات          🔄 فحص الجميع      📋 حالة القنوات
                            🧪 اختبار النشر
```

**تدفّق الربط** (كله من الهاتف):

| الخطوة | ما يحدث |
|---|---|
| 1️⃣ تضغط «⬜ 🎬 الأنمي» | البوت: «أرسل **أحد** هذه: `@my_anime` · `-1001234567890` · `t.me/+AbCdInvite`» |
| 2️⃣ ترسل المعرّف | البوت يسأل تيليجرام عن القناة فعلياً (`getChat` + `getChatMember`) |
| 3️⃣ التحقّق | عنوان القناة + هل البوت **أدمن**؟ |
| 4️⃣ | ✅ «تمّ الربط بنجاح» — أو ❌ + سبب واضح وحلّه |

**أمثلة أخطاء البوت وردوده**:

```
❌ لم أجد القناة @not_exist — تأكد من المعرّف (يفضّل @username)
❌ أنت لست أدمن — أضف البوت أدمن في القناة ثم اضغط «فحص الجميع»
❌ القناة خاصة — انسخ دعوة t.me/+... وارسلها بدل @username
```

**الأيقونات**: ✅ مربوط ومتحقّق · ⚠️ معرّف محفوظ لكن فحصه فشل · ⬜ لم يُضبط.

**أوامر إضافية مقترحة داخل البوت**: «🔄 فحص الجميع» (يعيد التحقّق من ٧ قنوات مرة واحدة) ·
«📋 حالة القنوات» (جدول: المعرّف، النوع، أدمن؟) · «🧪 اختبار النشر» (منشور تجريبي يُمحى فوراً) ·
«↩️ رجوع» و`/cancel` للتراجع عن أي خطوة.

**أين تُحفظ المعرّفات؟** في `state/channels_setup.json` داخل المستودع (لا أسرار — معرّفات فقط).
**أولوية القراءة**: الملف المخزَّن ← `extra.ENV_*` في `channels.yml` ← متغيّر البيئة.
أي أن `TELEGRAM_BOT_TOKEN` يبقى **سرّاً في GitHub Secrets** ولا يدخل المستودع أبداً.

```bash
python -m autonews.setup_main --status    # جدول ٠/٧ جاهز
python -m autonews.setup_main --panel     # إرسال لوحة الأزرار
python -m autonews.setup_main --poll      # التقاط ضغطاتك (يشتغل تلقائياً كل ٥ دقائق)
```

> **الحلقة مكتملة بلا حاسوب**: `.github/workflows/setup.yml` يعمل كل ٥ دقائق، يقرأ
> ضغطاتك، يربط القناة، ويحفظ الحالة في المستودع. تفتح تيليجرام على هاتفك فقط.

### ⚠️ حقيقة يجب أن تعرفها

نشر نفس الخبر من **نفس البوت** في قناة عامة وقناة متخصّصة = **تكرار يُزعج** من يتابع الاثنتين.
لذا الفصل الصحيح هو **استثناء** (كما فعلنا)، لا نسخ. والنمط الأقوى للنمو:

```
قناة عامة  →  كل خبر مهم (بوّابة النتائج)
قناة قطاعية →  كل خبر للقطاع + عمق (تقويم مواسم، جداول، تحليلات)
```

القطاعية **لا تكون نسخة أصغر** من العامة — تكون **أعمق**.

## 🎛 لوحة التحكّم — المراجعة الذكية والمواعيد

**المشكلة**: المراجعة اليدوية لكل منشور تُبطئ النشر، وإلغاؤها كلّياً خطر.
**الحل**: نمط **ذكي** — لا يسألك إلّا عن المنشور الذي يشكّ فيه النظام.

| النمط | متى يسألك؟ | متى ينشر فوراً؟ |
|---|---|---|
| 🤖 **ذكية** (افتراضي) | درجة جودة منخفضة · صياغة احتياطية · كلمات حسّاسة · بلا رابط مصدر | كل خبر سليم · **وكل خبر 🔴 عاجل بلا استثناء** |
| 👁 **كل منشور** | دائماً | لا شيء (حتى العاجل ينتظر) |
| 🚀 **بلا مراجعة** | أبداً | كل شيء |

```bash
# كل هذا بأزرار من الهاتف — لا ملفات ولا حاسوب
python -m autonews.setup_main --panel     # اللوحة
# 🎛 لوحة التحكّم  →  اختر قناة:
#    ⏸ إيقاف القناة          ← يوقف النشر فيها فوراً (المسار السريع أيضاً)
#    🌙 ساعات هدوء 23→06     ← ما يأتي ليلاً **يُؤجَّل لا يُلغى**
#    🤖 / 👁 / 🚀            ← نمط المراجعة
# 📥 ما ينتظرني             ← معاينة + ✅ نشر / 🗑 حذف
```

**قاعدة ذهبية**: ساعات الهدوء **تُؤجّل** ولا تُلغي. ما يأتي الساعة ٣ فجراً يُنشر
تلقائياً الساعة ٦ — إلّا العاجل، فيتجاوز الهدوء دائماً (السرعة شرط أساسي).

ما ينتظر موافقتك يبقى في `state/control.json` **ولا يُنشر تلقائياً أبداً**، حتى لو
مرّ عليه أسبوع — بل يُحذف بعد ٤٨ ساعة كي لا يتراكم.

## 🖋 بصمة الملكية — «هذا المنشور لي»

ثلاث طبقات، كلها تعمل تلقائياً على كل منشور وصورة:

| # | الطبقة | ماذا تفعل | أين تظهر |
|---|---|---|---|
| ١ | **توقيع نصّي** | `📡 @قناتك` في آخر المنشور (أو `via @قناتك` على X) | يراها كل قارئ |
| ٢ | **علامة مائية على الصورة** | شريط داكن شبه شفّاف باسم قناتك، بخطّ عربي متّصل | ملتصقة بالصورة حتى لو نُشرت في قناة أخرى |
| ٣ | **علامة خفيّة** | اسم قناتك مُرمَّزاً بمحارف صفرية العرض داخل النصّ | لا تُرى، لكنها **تنتقل مع النسخ واللصق** |

**إثبات السرقة بأمر واحد**:

```bash
python -m autonews.brand_main --prove "النصّ المسروق كما هو"
# ✅ العلامة تعود إلى @your_channel
```

**لماذا العلامة الخفيّة؟** تيليجرام لا يفهرس `#` كوسم فعلي، فالاعتماد على الهاشتاغ
لحماية الحقوق وهم. والصور تُنسخ بلا مصدر. العلامة الخفيّة لا تُزال بنسخ ولصق،
وتكلفتها صفر (٤ محارف غير مرئية لكل بايت، ≤ ٦٠ محرفاً لاسم كامل).

**ضبطها** (من البوت أو الأمر):

```
🖋 البصمة → أرسل @اسم_قناتك → ✅ تمّت
```

```bash
python -m autonews.brand_main --show                     # بصمات كل القنوات
python -m autonews.brand_main --set tg_main --handle my_channel
python -m autonews.brand_main --preview tg_main          # نموذج منشور + صورة موسومة
```

> 🎨 **العربية على الصور بلا مكتبات**: لا `arabic-reshaper` ولا `python-bidi`.
> التشكيل (اتصال الحروف + ترتيب RTL) منفَّذ داخل `arabic_text.py` — كل اعتمادية
> إضافية نقطة فشل في Actions. Pillow اختيارية: بلاها يُنشر النصّ بلا ختم صورة.

## 🎬 عمود الأنمي — نفس المحرّك، بمنطق مختلف

المبدأ: **لا نُكرّر النظام**. محرّك الأخبار (سحب → تصنيف → صياغة → نشر → قياس)
واحد. القطاع الجديد يضيف ثلاث طبقات فقط: **كاشف · مفردات · سياسة نشر**.

### ١) لماذا سياسة مختلفة؟

| البُعد | الأخبار | الأنمي |
|---|---|---|
| ما هو «الخبر»؟ | **النتيجة** (لا ننشر الحادث الخام) | **الإعلان نفسه** (لا يوجد حادث ولا نتائج) |
| التأجيل | حادث بلا نتائج ⇒ يُؤجَّل | إعلان ⇒ **يُنشر فوراً** |
| الأسماء | تُترجم | **تبقى لاتينية** (Kyoto Animation ≠ «كيوتو أنيميشن») |
| البرومبت | أخبار/نتائج | محرّر مجلة أنمي |

```yaml
verticals:
  anime:
    enabled: true
    min_score: 3.0             # رفعها = الأهمّ فقط
    publish_policy: announcement   # الإعلان خبر
    keep_original_names: true
    append_glossary: true      # سطر «🎬 الأسماء الأصلية»
    translate: true
    skip_incident_gate: true   # لا يمرّ على بوّابة «حدث بلا نتائج»
```

### ٢) كاشف الأنمي — ثلاث طبقات دقّة

| الطبقة | تُنقذ أي حالة؟ |
|---|---|
| كلمات (أنمي/مانغا/حلقة/أوتاكو) | «أنمي Mercedes يكشف عن تريلر» |
| استوديوهات معروفة (26 استوديو) | «MAPPA reveals new visuals» |
| **جدول أعمال معروفة** (24 عملاً) | «بليتش يعود بموسم جديد» و«Black Clover حلقة 5» — بلا كلمة «أنمي» إطلاقاً |

**تصنيف الحدث** بأولوية دقيقة: `انتهاء ← طاقم ← تريلر ← عرض ← موسم ← إعلان`
(«Season 2 Premieres October» = **عرض**، لا «موسم»).

**الرفض الذكي**: أخبار «سوق الأنمي 28 مليار دولار» **ليست خبر أنمي** — بلا عمل ولا استوديو ولا حدث ⇒ تُرفض.

### ٣) حماية الأسماء الأصلية

```
🎬 الأسماء الأصلية: Shiba Inu Rooms · Hiroshi Fukuda
```

مستخرج من العنوان بلا AI، مع تصفية صارمة: كلمتان فأكثر، بلا كلمات عامّة
(Gets/Reveals/Teaser/Summer 2027…)، وطوله ≤ 40 حرفاً. النتيجة على ٥ عناوين حقيقية:
`Shiba Inu Rooms` · `Jujutsu Kaisen` · `Frieren: Beyond Journey's End` — كلها صحيحة.

## 📊 الحزمة A — القياس: UTM + لوحة HTML + أفضل أسبوع

**المشكلة**: تنشر بلا أن تعرف أي منشور جلب قارئاً. «الزيارات من تيليجرام» لا تخبرك
أيّ بطاقة نتيجة عملت وأيّها مرّت صامتة.

### ١) 🔗 وسوم UTM — قياس لكل منشور

```yaml
links:
  enabled: true
  medium: social
  campaign_prefix: autonews
  keep_existing: true     # لا يلمس رابطاً فيه utm_source مسبقاً
```

كل رابط يُنشر يصبح قابلاً للت attribution:

```
https://shafaq.com/ar/news?utm_source=telegram&utm_medium=social
  &utm_campaign=autonews-outcome&utm_content=424d5a
```

| الوسم | القيمة | الفائدة |
|---|---|---|
| `utm_source` | المنصّة | أي منصّة تجلب فعلاً؟ |
| `utm_campaign` | `regular` · `flash` · `outcome` · `matrix` | **هل بطاقات النتائج تتفوّق على الأخبار العادية؟** |
| `utm_content` | بصمة ٦ أحرف | أي منشور بعينه؟ |

**حمايات**: لا يمسّ رابطاً موسوماً سابقاً · يحترم `?v=` في يوتيوب · لا يعمل على غير HTTP ·
الصورة تُجلب من **الرابط النظيف** قبل الوسم (كي لا يفشل `og:image`).

### ٢) 🖥 لوحة الأداء — ملف HTML واحد يعمل بلا إنترنت

```bash
python -m autonews.dashboard_main               # آخر ٧ أيام
python -m autonews.dashboard_main --days 30     # آخر شهر
python -m autonews.dashboard_main --dry-run     # ملخّص في الطرفية بلا كتابة
```

تُبنى من `state/state.json` وحدها — **بلا خدمات تحليلات، بلا CDN، بلا شبكة**:

| القسم | ماذا يُظهر |
|---|---|
| بطاقات علوية | إجمالي المنشورات · بطاقات النتائج (ونسبتها) · عاجل · تحديثات |
| 📈 حسب الساعة | رسم SVG بأعمدة (توقيت بغداد) + **ساعات بلا نشر** = فرص ضائعة |
| 🏷 أنواع المنشورات | نتيجة · عاجل · تحديث · خريطة · تفاوت · عادي |
| 📡 أكثر المصادر | بأسماء عربية (واع — محلي · شفق نيوز…) |
| ⭐ أفضل المنشورات | مرتبة بالأثر التحريري، والمنشور الواحد **يُدمج** عبر منصّاته الثلاث |

تُخرج ٣ ملفات: `dashboard.html` · `best_of_week.md` · `dashboard.json` (للاستخدام البرمجي).

### ٣) ⭐ «أفضل أسبوع» — جاهز للنشر

```markdown
# أفضل ما نشرناه هذا الأسبوع
> آخر 7 أيام · 15 منشوراً · 40% منها بطاقات نتائج

## 📋 نتائج تستحقّ التذكير
1. **📋 نتائج: تعطيل الدوام في البصرة وميسان وذي قار** — telegram
...
## 🕳 فجوات التغطية (فرص ضائعة)
- ساعات بلا أي نشر: 0:00، 1:00، 2:00، 3:00
```

يُضاف تلقائياً إلى ملخّص GitHub Actions، ويُرفع كـ Artifact.

**درس تصميم**: أول نسخة من «الأفضل» كرّرت نفس الخبر ٣ مرّات لأن المنشور الواحد
يُرسل لتيليجرام وفيسبوك وX. القاعدة: **القياس يوحّد، لا يعدّ** — ندمج أولاً ثم نرتّب.

## ⚙️ التخصيص

### إضافة مصدر
```yaml
# config/settings.yml
sources:
  - id: my_source
    name: مصدري
    url: https://example.com/feed.xml
    lang: ar
    tags: [اقتصاد]
    enabled: true
```

### إضافة قناة بأسلوب خاص
```yaml
# config/channels.yml
channels:
  - id: tg_economy
    name: "قناة الاقتصاد"
    platform: telegram
    sources: ["*"]
    keywords: [اقتصاد, تضخّم, دولار, نفط]     # فقط ما يخصّ الاقتصاد
    style: "أسلوب تحليلي مبسّط يشرح أثر الخبر على جيب المواطن في سطر واحد."
    max_chars: 4096
    add_hashtags: 4
    max_posts_per_run: 2
    credentials:
      bot_token: TELEGRAM_BOT_TOKEN
      chat_id: TELEGRAM_ECONOMY_CHAT_ID
```

### إضافة منصّة جديدة (مثلاً لينكدإن)
```python
# src/autonews/publishers/linkedin.py
from .base import Publisher

class LinkedInPublisher(Publisher):
    platform = "linkedin"
    def validate(self) -> str:
        return "" if self.channel.env("access_token") else "توكن لينكدإن مفقود"
    def _send(self, text: str) -> str:
        status, body = self._request(
            "https://api.linkedin.com/v2/ugcPosts",
            data={...}, headers={"Authorization": f"Bearer {self.channel.env('access_token')}"},
        )
        return body
```
ثم أضِفها إلى `registry` في `publishers/base.py` وفي قائمة المنصّات المسموحة في `config_loader.py`.

## 📊 مؤشّرات الجودة والسلامة

- **لا اختلاق**: تعليمات النظام تمنع أي معلومة غير موجودة في النص الأصلي، والقالب الاحتياطي يستخدم النص الأصلي حرفياً عند فشل AI.
- **حدود المنصّات**: التقسيم التلقائي لتيليجرام (4096)، الاقتطاع الذكي لـ X (280)، والتقييد لفيسبوك (1800) — مع احتساب الرابط.
- **سقوف النشر**: `max_posts_per_run` لكل قناة + `max_items_per_run` للتشغيل = حماية من الفيضان وتوفير للحصة.
- **مراجعة المحتوى الحسّاس**: الحقل `sensitive` في مخرجات النموذج يتيح لك (اختياريًا) استبعاد الأخبار الحساسة من النشر الآلي.

## 🧯 استكشاف الأخطاء

| العرض | السبب | الحل |
|---|---|---|
| `لا توجد مفاتيح Gemini` | السرّ غير مضاف | أضِف `GEMINI_API_KEYS` وأعد التشغيل |
| `⏳ حصة منتهية` متكرّر | كل المفاتيح من نفس المشروع | أضِف مفاتيح من حسابات/مشاريع مختلفة |
| `chat not found` | البوت ليس مشرفاً | أضِفه مشرفاً في القناة وتأكد من `chat_id` |
| لا يُنشر شيء أبداً | كل المقالات مكرّرة | احذف/حدّث `state/state.json` أو ارفع `max_age_hours` |
| `HTTP 403` من مصدر | الموقع يحجب الطلبات | عطّل المصدر أو استخدم مرآة RSS |
| فشل فيسبوك `(#200)` | صلاحيات ناقصة | أعد توليد توكن الصلاحية بـ `pages_manage_posts` |

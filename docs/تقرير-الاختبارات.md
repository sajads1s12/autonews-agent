### تفصيل النتيجة ٩ (الوحيدة غير المكتملة)

```
⚠️ [ 9] استعادة الحالة بين التشغيلات
      المستودع الخاص غير مضبوط
      ↳ أضف STATE_REPO و STATE_REPO_TOKEN
```

**هذا ليس عطلاً في الكود** — المزامنة مُختبَرة بالكامل بـ ١٩ اختباراً حقيقياً
على مستودعات git فعلية. الناقص هو **السرّان في حسابك**، وهما يحتاجان توكنك.
بعد إضافتهما يتحوّل التحذير إلى ✅ تلقائياً.

**حتى قبل إضافتهما:** النظام يعمل — لكن الذاكرة تعيش داخل بيئة التشغيل فقط،
فكل تشغيل جديد يبدأ بلا معرفة بما نُشر ⇒ **خطر نشر مكرر**. لذلك إضافتهما ليست
تحسيناً بل شرط للاستمرار الصحيح.

## ٢) اختبارات المزامنة (git حقيقي، بلا شبكة)

| الاختبار | ما يثبته |
|---|---|
| `test_first_save_creates_private_repo_content` | المستودع الخاص الفارغ يُهيّأ ويُدفع |
| `test_save_does_not_store_token_in_git_config` | **التوكن لا يُكتب على القرص** |
| `test_full_cycle_restores_state` | حفظ ← تشغيل جديد ← استعادة = نفس الحالة |
| `test_dedup_survives_restore` | **بصمة منشورة تنجو من إعادة التشغيل** |
| `test_concurrent_saves_do_not_corrupt_state` | تشغيلان متزامنان بلا فقدان |
| `test_save_never_raises_on_broken_remote` | مستودع معطوب لا يوقف النشر |
| `test_restore_does_not_wipe_local_config` | الاستعادة لا تطمس إعدادك |
| `test_restore_on_empty_repo_is_safe` | أول تشغيل أبداً لا ينفجر |
| `test_scrub_hides_known_secret_shapes` | الأسرار تُحجب من السجلات |
| `test_state_workdir_is_separate_from_public_repo` | عزل تام بين المستودعين |

**اكتشاف مهمّ أثناء الاختبار:** التصميم الأول (remote داخل نفس المستودع)
كانت له ثلاث مشاكل حقيقية:
1. `git add` يفشل صامتاً بسبب `skip-worktree`
2. `rebase` يتعارض في JSON دائماً ⇒ فشل الدفع
3. خطر دفع الحالة إلى المستودع العام

**أُعيد التصميم:** مجلد `.state-repo/` منفصل + `merge -s ours` عند التعارض.
الاختبارات كشفت هذا ولم يكن ليظهر بمراجعة الكود.

### اختبار فحص تاريخ Git (إثبات عملي)

زروعنا سرّاً في commit ثم حذفناه من آخر نسخة:

```
$ bash scripts/check_secrets.sh
✅ لا أسرار متسرّبة                        ← الملفات الحالية نظيفة

$ bash scripts/check_secrets.sh --history
❌ سرّ في تاريخ Git: [0-9]{8,12}:AA[A-Za-z0-9_-]{30,}
   e201dc80:old_secret.py:1:TELEGRAM_TOKEN = "8913…"
```

**هذا يثبت أن الفحص ليس شكلياً.**

## ٦) ما لا نستطيع ضمانه (صراحة)

| الوعد | الحقيقة |
|---|---|
| «توقيت دقيق كل ٥ دقائق» | ❌ Cron في GitHub يتأخّر ٥–٣٠ دقيقة عند الازدحام |
| «سيرفر دائم متّصل» | ❌ كل تشغيل بيئة جديدة تُدمَّر بعده |
| «يعمل ٢٤/٢٤ بلا انقطاع» | ⚠️ يعمل مجدولاً — فجوات بين التشغيلات طبيعية |
| «صفر كلفة دائماً» | ✅ للمستودع العام · ⚠️ الخاص: ٢٠٠٠ دقيقة/شهر |
| «الأخبار تظهر في الثانية» | ❌ أقرب واقع: ٥–٢٠ دقيقة عبر `flash.yml` |

**لمن يريد ثوانٍ حقيقية:** مشغّل مستمر (VPS ~٢$ أو Railway) بنفس الأمر:
`python -m autonews.flash_main --interval 30` — والمشروع يدعمه أصلاً.

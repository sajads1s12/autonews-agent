# 📱 اعرف معرّف قناتك واحفظه — أداة واحدة

أشهر سبب لفشل النشر: **`chat not found`** — إمّا المعرّف خطأ أو البوت ليس مشرفاً.
هذه الأداة تحلّ الأمر نهائياً لأنها **تتحقّق من تيليجرام نفسه** ولا تعتمد على التخمين.

---

## ⚡ الطريقة السريعة (٣ أوامر)

```bash
# ١) صدّر التوكن (من @BotFather)
export TELEGRAM_BOT_TOKEN=123456789:AA...

# ٢) أضف البوت مشرفاً في قناتك، ثم انشر أي رسالة فيها، ثم:
python -m autonews.chatid

# ٣) انسخ السطرين الظاهرين إلى GitHub Secrets
#    TELEGRAM_BOT_TOKEN=...
#    TELEGRAM_CHAT_ID=-1001234567890
```

النتيجة المتوقّعة:

```
🤖 البوت: @my_bot (AutoNews) — التوكن صالح ✅

🔎 عُثر على 2 محادثة:

1) ✅ قناتي الإخبارية
    المعرّف : -1001234567890
    النوع   : channel · مشرف: نعم
    البديل  : @my_channel

────────────────────────────────────────────────────
📋 انسخ هذين السطرين إلى GitHub Secrets:

TELEGRAM_BOT_TOKEN=<توكن البوت>
TELEGRAM_CHAT_ID=-1001234567890
```

## 🎯 الحفظ التلقائي

| الأمر | ماذا يفعل |
|---|---|
| `--chat @my_channel --test` | يتحقّق من قناة محدّدة **ويرسل رسالة اختبار** واحدة |
| `--save tg_main` | يحفظ المعرّف داخل `config/channels.yml` للقناة المطلوبة |
| `--save-env` | يكتب `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` في `.env` (محلي، **لا يُرفع**) |

مثال كامل:

```bash
python -m autonews.chatid --chat @my_channel --test --save tg_main --save-env
```

### كيف يعمل «الحفظ» بلا تسريب أسرار؟

النظام يقرأ السرّ من **متغيّر بيئة** (`credentials.chat_id: TELEGRAM_CHAT_ID`).
الأداة لا تكتب السرّ في المستودع، بل تكتب **المعرّف** في `extra.ENV_CHAT_ID` —
والنظام يقرأه بأولوية أعلى من متغيّر البيئة:

```yaml
  - id: tg_main
    credentials:
      chat_id: TELEGRAM_CHAT_ID     # ← يبقى سرّاً في GitHub Secrets
    extra:
      ENV_CHAT_ID: "-1001234567890"  # ← يُضاف تلقائياً بالأداة
```

النتيجة: القناة تعمل فوراً، ولو تغيّرت لاحقاً تكفي إعادة الأمر — بلا لمس GitHub.

## 🧯 إن لم تظهر أي محادثة

| السبب | الحل |
|---|---|
| البوت لم يُضف للقناة | أضفه (Settings → Administrators → Add Admin) |
| أُضيف لكن بلا رسالة | انشر **أي رسالة** في القناة ثم أعد الأمر |
| التوكن خطأ | انسخه كاملاً من `@BotFather → API Token` |
| البوت ليس مشرفاً في قناة | `getChatMember` سيقول ذلك صريحاً |
| معرّف سالب خاطئ | القنوات تبدأ بـ `-100` — لا تستخدم `@name` إن كانت خاصة |

> 💡 **قناة خاصة؟** استخدم المعرّف الرقمي (`-100…`) لا `@name`.
> **قناة عامة؟** كلاهما يعمل، لكن الرقمي أدقّ وأثبت.

# ▶️ التشغيل لأول مرّة — من الصفر إلى نشر حقيقي

> **الوقت:** ٣٠ دقيقة · **كل شيء من الهاتف** · **بلا VPS وبلا حاسوب**

---

## الخريطة

```
مستودع عام  (autonews-agent)  →  الكود + workflows   ← دقائق مجانية بلا حدّ
مستودع خاص  (autonews-state)  →  الحالة + المعرّفات  ← ذاكرة البوت
GitHub Secrets               →  المفاتيح            ← لا تظهر في أي ملف
```

---

## المرحلة ١ — المستودع العام (١٠ دقائق)

### ١.١ أنشئه

```
github.com → ➕ → New repository
  Name     : autonews-agent
  Visibility: ✅ Public        ← مهمّ: دقائق Actions مجانية بلا حدّ
  ☑ Add a README
```

### ١.٢ ارفع الكود

> **لماذا ملف واحد؟** رفع المجلدات غير ممكن من متصفح الهاتف، و`.github/`
> مجلد مخفيّ لا يقبله السحب والإفلات — وهو قلب الجدولة.

```
مستودعك → < > Code → Codespaces → Create codespace on main
```

في الـ Terminal:

```bash
cat > restore.sh        # الصق محتوى docs/أرشيف-المشروع.md ثم Ctrl+D
bash restore.sh
git add -A
git commit -m "🚀 النسخة الأولى"
git push
```

**تحقّق حتمي:**

```bash
ls -a .github/workflows/     # ٤ ملفات
ls -a .github/actions/       # setup · state
```

### ١.٣ صلاحيات

```
Settings → Actions → General → Workflow permissions
   → ✅ Read and write permissions → Save
```

> هذه للمستودع ككل. مساراتنا نفسها تطلب `contents: read` فقط (أقلّ صلاحية).

## المرحلة ٢ — المستودع الخاص (٥ دقائق)

### الطريقة الأسرع: أمر واحد

```bash
# ١) توكن GitHub بصلاحية repo
#    github.com/settings/tokens → Generate new token
export STATE_REPO_TOKEN="ghp_..."

# ٢) ينشئ المستودع الخاص + يدفع الحالة + يطبع التعليمات
bash scripts/bootstrap_state_repo.sh
```

سينتهي بـ:

```
✅ المستودع الخاص جاهز: https://github.com/you/autonews-state

📋 أضف هذين السرّين في المستودع العام:
   STATE_REPO        = you/autonews-state
   STATE_REPO_TOKEN  = (نفس التوكن)
```

### يدوياً (بديل)

```
github.com → ➕ → New repository
  Name: autonews-state   Visibility: ✅ Private   (بدون README)
```
ثم أضف السرّين في المستودع العام ومرّرهما.

## المرحلة ٣ — الأسرار (٧ دقائق)

`مستودعك العام → Settings → Secrets and variables → Actions`

| الاسم | القيمة |
|---|---|
| `GEMINI_API_KEYS` | ٥ مفاتيح مفصولة بفواصل |
| `TELEGRAM_BOT_TOKEN` | من @BotFather |
| `TELEGRAM_ADMIN_CHAT_ID` | رقمك من @userinfobot |
| `STATE_REPO` | `you/autonews-state` |
| `STATE_REPO_TOKEN` | الـ PAT |
| `SETUP_ALLOWED_USERS` | رقمك (حماية البوت) |

📖 التفاصيل الكاملة: [`docs/أسرار-GitHub.md`](أسرار-GitHub.md)

## المرحلة ٤ — الفحص قبل التشغيل ⭐

```
Actions → 🧪 CI — فحص الجودة والاختبارات → Run workflow
```

**يجب أن يظهر ✅ أخضر.** هذا يضمن:

| ما يفحصه | عدد الفحوص |
|---|---|
| الاختبارات الكاملة | ٥١٤ اختباراً |
| تسرّب الأسرار (ملفات + تاريخ) | ٨ أنماط |
| بنية المستودع (لا حالة عامة) | ٦ فحوص |
| صلاحية الـ workflows | ٤ ملفات |

من طرفية، الفحص الشامل (١٠ اختبارات):

```bash
python -m autonews.preflight            # بلا شبكة
python -m autonews.preflight --online   # + Gemini + تيليجرام
```

## المرحلة ٥ — ربط القنوات (٥ دقائق)

```
Actions → 🎛 لوحة التحكّم والبوت → Run workflow
   send_panel = true → Run
```

**افتح تيليجرام** ← وصلك:

```
🎛 لوحة التحكّم
📰 الأخبار العامة — ⬜ ناقصة
🎬 الأنمي — ⬜ ناقصة
...
[➕ قناة جديدة] [🧠 اربط بالاسم] [📊 الإحصاءات]
```

اضغط **`🧠 اربط بالاسم`** وأرسل:

```
-1001234567890 | أخبار الأنمي والمانغا
```

الردّ:

```
🎉 تمّ الربط
القناة: أخبار الأنمي والمانغا
المعرّف: -1001234567890

🎌 عرفت القطاع: أنمي ومانغا
• الوسوم: أنمي, مانغا
• المصادر: myanimelist_news, gnews_anime_ar, animecorner, gnews_anime_new
```

> 🔒 البوت **لا يطلب التوكن أبداً** — المعرّفات فقط.
> بعد الربط: انتظر ٥ دقائق ثم `Actions` ← يجب أن يظهر حفظ الحالة ناجحاً.

## المرحلة ٦ — تشغيل تجريبي (٢ دقيقة)

```
Actions → 🤖 الدورة الأساسية → Run workflow
   dry_run = true ✅  → Run
```

**اقرأ السجلّ** — يجب أن ترى:

```
✅ استُعيدت الحالة (11 ملفاً · 3 JSON)
📰 42 مقالاً من 38 مصدراً
🚫 تجاهل 18 مكرراً        ← منع التكرار يعمل!
📝 سأراجع 6 مرشّحين
✅ حُفظت الحالة (2 ملفاً)
```

> **الوضع التجريبي لا ينشر شيئاً.** إن رَأيت «🚫 تجاهل … مكرراً» فالنظام سليم.

## المرحلة ٧ — النشر الحقيقي 🚀

### الشروط (لا تنتقل قبلها)

- [ ] CI أخضر
- [ ] المزامنة تعمل (ظهر «✅ استُعيدت/حُفظت الحالة»)
- [ ] تشغيل تجريبي بلا أخطاء
- [ ] قناة واحدة مربوطة على الأقلّ
- [ ] `python -m autonews.preflight` بلا ❌

### التشغيل

```
Actions → 🤖 الدورة الأساسية → Run workflow
   dry_run = false → Run
```

خلال ١–٢ دقيقة يجب أن يظهر منشور في قناتك، ويحمل بصمة `@اسم_قناتك`.

### ثم انتظر الجدولة

| المسار | التوقيت | ملاحظة |
|---|---|---|
| ⚡ المسار السريع | كل ٥ دقائق | العاجل — تأخير واقعي ٥–٢٠ دقيقة |
| 🤖 الدورة الأساسية | كل ساعتين | الأخبار العادية |
| 🎛 التحكّم والبوت | كل ٥ دقائق | الأزرار والموافقات |

> ⚠️ **صدق ضروري:** Cron في GitHub **ليس دقيقاً**. قد يتأخّر ٥–٣٠ دقيقة عند
> الازدحام، وقد يُلغى نادراً. GitHub Actions ليس سيرفراً دائماً — كل تشغيل
> بيئة جديدة تُبنى ثم تُدمَّر، والذاكرة تعيش في المستودع الخاص.

## بعد أسبوع — ماذا تراقب؟

| المؤشّر | أين | المطلوب |
|---|---|---|
| نسبة النجاح | Actions | > ٩٠٪ |
| عدد المنشورات/يوم | `state/state.json` في الخاص | غير صفر |
| مصادر فاشلة | `logs/report.md` | أقلّ من ٣ |
| حجم الحالة | حجم `state.json` | أقلّ من ٢ م.ب |

من البوت: **`📊 الإحصاءات`** يعطيك الملخّص.

## أعطال شائعة

| العَرَض | السبب | الحلّ |
|---|---|---|
| `⚪ المزامنة غير مضبوطة` | سرّان ناقصان | راجع المرحلة ٣ |
| `HTTP 401` | PAT منتهٍ | جدّده |
| كل تشغيل ينشر نفس الخبر | بلا مزامنة | فعّل `STATE_REPO` |
| البوت لا يرد | `SETUP_ALLOWED_USERS` يمنعك | أضف رقمك أو أفرغه |
| `chat not found` | البوت ليس مشرفاً | أضفه مشرفاً في القناة |
| `لا مفاتيح GEMINI` | اسم السرّ خطأ | `GEMINI_API_KEYS` بالحرف الكبير |
| فشل `restore.sh` | لصق ناقص | أعد النسخ من الرابط الخام |
| `.github` لم تُرفع | مجلد مخفي | `git add -A` ثم `ls -a .github` |

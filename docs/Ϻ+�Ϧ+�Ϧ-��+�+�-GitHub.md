## الخطوة ٢ — 🔑 سوّي مفتاح دخول (مرّة واحدة)

الطريقة القديمة (كلمة السرّ) **لم تعد تعمل**. GitHub يطلب **Token**.

```
github.com  →  صورتك (فوق يمين)  →  Settings
   →  أسفل القائمة اليسرى: Developer settings
   →  Personal access tokens  →  Tokens (classic)
   →  Generate new token (classic)
```

| الحقل | القيمة |
|---|---|
| Note | `autonews-upload` |
| Expiration | `30 days` |
| **Scopes** | ☑ **repo** (كل ما تحته) |
| | ☑ **workflow** ← ⚠️ **إجباري** وإلا لن تُرفع ملفات `.github` |

اضغط **Generate token** ← **انسخه واحفظه فوراً** (لن يظهر مرّة ثانية).

> 🔒 هذا المفتاح يقدر يعدّل مستودعاتك. **لا تشاركه ولا تضعه في محادثة.**
> احذفه من نفس الصفحة بعد ما تخلص الرفع.

## الخطوة ٣ — ارفع الملفات ⭐ (الطريقة الوحيدة على الهاتف)

### لماذا لا يمكن «رفع مجلد»؟

| الطريقة | تعمل على الهاتف؟ | السبب |
|---|---|---|
| Drag & Drop | ❌ | رفع المجلدات **للمتصفّح على الحاسوب فقط** |
| Drag & Drop | ❌ | **لا يرفع المجلدات المخفيّة** مثل `.github` — وهي قلب الجدولة |
| رفع ملف ملفاً | ❌ | ١٠٠+ ملف = ساعة على الهاتف |
| ✅ **ملف واحد** | ✅ | `restore.sh` يفكّ نفسه ويُنشئ كل شيء |

---

### ٣.١ — افتح الطرفية السحابية

```
github.com  →  مستودعك  →  اضغط زر  < >  (Code)
   →  تبويب  Codespaces  →  Create codespace on main
```

انتظر ~٦٠ ثانية حتى تُفتح الشاشة (VS Code في المتصفّح).

إذا ضاقت الشاشة على الهاتف، **لفّ الجهاز أفقياً** أو استخدم `Terminal → New Terminal`.

---

### ٣.٢ — نزّل ملف الأرشيف

في شاشة Codespaces: افتح ملف `docs/أرشيف-المشروع.md` في المشروع —
لكن هذا الملف **في الوركسبيس عندك** (تقدر تفتحه من هذه المحادثة).

في الطرفية (Terminal) اسحب/الصق الأوامر التالية:

```bash
# ١) حمّل ملف الأرشيف (الرابط من صفحة الأرشيف عندك)
curl -L -o /tmp/restore.sh "الرابط_هنا"

# ٢) شغّله
bash /tmp/restore.sh

# ٣) تأكّد أن كل شيء وصل
ls -a
```

### ٣.٣ — ارفع كل شيء

```bash
git add -A
git commit -m "🚀 نسخة كاملة: بوت + قنوات + فيسبوك + قطاعات"
git push
```

**النتيجة المتوقّعة:**


### ✅ تأكّد أن `.github` وصلت (أهمّ فحص)

```bash
ls -a .github/workflows/
```

يجب أن ترى **٥ ملفات**:

```
autonews.yml   ci.yml   control.yml   flash.yml   setup.yml
```

إن كانت فارغة ← الملفات المخفيّة لم تُرفع، أعد `git add -A` وشغّل `git status` للتأكد.

## الخطوة ٣.٥ — فعّل صلاحية الكتابة (⚠️ بدونها لا يعمل شيء)

النظام يحتاج **يحفظ حالته** (يمنع تكرار الأخبار) ويحدّث القنوات.

```
github.com  →  مستودعك  →  Settings
   →  Actions  →  General
   →  أسفل الصفحة: Workflow permissions
   →  ✅ Read and write permissions
   →  Save
```

| بدون هذه الخطوة | النتيجة |
|---|---|
| `state.json` لا يُحفظ | 🔁 **ينشر نفس الخبر كل مرة** |
| القنوات لا تُربط | ❌ البوت يفشل بالحفظ |

## الخطوة ٤ — 🔐 أضف الأسرار (أهمّ خطوة)

```
github.com  →  مستودعك  →  Settings
   →  Secrets and variables  →  Actions
   →  New repository secret
```

### الأسرار المطلوبة — ٣ فقط للبدء

| # | الاسم | القيمة | من أين |
|---|---|---|---|
| ١ | `TELEGRAM_BOT_TOKEN` | `8913…` **الجديد بعد التبديل** | @BotFather |
| ٢ | `TELEGRAM_ADMIN_CHAT_ID` | **معرّفك الشخصي** (رقم) | @userinfobot |
| ٣ | `GEMINI_API_KEY_1` | `AQ.…` **الجديد** | AI Studio |

### الأسرار المكمّلة (أضفها كلها)

| # | الاسم | القيمة |
|---|---|---|
| ٤-٧ | `GEMINI_API_KEY_2` … `_5` | مفاتيحك الأربعة الأخرى |
| ٨ | `FACEBOOK_PAGE_TOKEN` | التوكن الدائم الجديد |
| ٩ | `FACEBOOK_PAGE_ID` | `1328940316978827` *(أو اتركه — محفوظ في الملف)* |

### اختيارية

| الاسم | متى تحتاجه |
|---|---|
| `SETUP_ALLOWED_USERS` | معرّفك، لتأمين البوت (يُنصح به) |
| `TELEGRAM_CHAT_ID` | معرّف القناة العامة القديمة |
| `X_API_KEY` … | ❌ تجاهلها — حساب X غير مستخدم |

### ⚠️ ثلاث قواعد عند الإضافة

1. **الاسم بالحرف الكبير تماماً** — `GEMINI_API_KEY_1` لا `gemini_api_key_1`
2. **بلا مسافات** — لا مسافة قبل القيمة ولا بعدها
3. **Password ≠ Secret** — الذي تريده هو **Repository secret**

## الخطوة ٥ — أول تشغيل (تجريبي)

```
github.com  →  مستودعك  →  تبويب  Actions
   →  من اليسار:  🧪 CI — فحص الجودة والاختبارات
   →  Run workflow  →  Run
```

انتظر ~٢ دقيقة. تريد أن ترى **✅ أخضر**.

ثم:

```
من اليسار:  ⚙️ بوت إعداد القنوات  →  Run workflow
   ☑ send_panel = true  →  Run
```

**افتح تيليجرام** ← وصلك:

```
🔧 لوحة إعداد القنوات
🎬 الأنمي — ⬜ ناقصة
⚽ الرياضة — ⬜ ناقصة
...
```

اضغط **`🧠 اربط بالاسم`** ← أرسل:

```
-1001234567890 | أخبار الأنمي والمانغا
```

## الخطوة ٦ — شغّل النشر الفعلي

```
Actions  →  🗞 النشر الدوري  →  Run workflow
   →  ☑ dry_run = false   (إن وُجد)
   →  Run
```

خلال دقيقة يجب أن يظهر منشور في قناتك.

| `autonews.yml` الدوري | كل ساعتين |

|---|---|

## 🧯 أعطال شائعة

| العَرَض | السبب | الحلّ |
|---|---|---|
| `workflow` permission error | نسيت scope `workflow` | أعد إنشاء التوكن مع ☑ workflow |
| رفع، لكن Actions لا تعرض شيئاً | `.github` لم تُرفع | `git add -A` ثم `ls -a .github/workflows/` |
| `401 Unauthorized` في Push | التوكن انتهى/خاطئ | توكن جديد |
| كل تشغيل ينشر نفس الخبر | لا صلاحية كتابة | الخطوة ٣.٥ |
| `chat not found` | البوت ليس مشرفاً | أضفه مشرفاً في القناة |
| `لا مفاتيح` في السجلّ | اسم السرّ خطأ | `GEMINI_API_KEY_1` بالحرف الكبير |
| Bot لا يرد | offset قديم | `Run workflow` مرّة أخرى |

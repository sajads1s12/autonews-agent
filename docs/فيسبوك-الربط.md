# 📘 فيسبوك — أي تطبيق تختار، وكيف تضيف الصفحة، وأي أسرار تحتاج

خلاصة سريعة في جدول واحد، ثم التفصيل:

| السؤال | الجواب |
|---|---|
| **أي تطبيق؟** | تطبيق **Business** على [developers.facebook.com](https://developers.facebook.com) — لا تختار Consumer |
| **أي نوع استخدام؟** | **Business** مرة أخرى داخل لوحة التطبيق |
| **كم سرّاً تحتاج؟** | **٢ فقط**: `FACEBOOK_PAGE_ID` + `FACEBOOK_PAGE_TOKEN` |
| **التوكن من أين؟** | من **Graph API Explorer** ← اختر صفحتك ← `Get Page Access Token` |
| **كم يدوم؟** | توكن المستخدم: **٦٠ دقيقة** (مؤقّت) · توكن الصفحة الممتدّ: **دائم** |
| **ما الصلاحيات؟** | `pages_show_list` · `pages_manage_posts` · `pages_read_engagement` |
| **هل تحتاج مراجعة Meta؟** | **لا** — ما دمت تنشر في صفحتك أنت (لا في صفحات الآخرين) |

> ⚠️ **أهم نقطة**: لا تستخدم «Instagram API» ولا «Messenger» — تحتاج **Facebook Login
> for Business** فقط. أي تطبيق آخر = أسابيع تعقيد بلا فائدة.

---

## ٠) من أي حساب أُنشئ الصفحة؟ ⭐ اقرأ هذا أولاً

**قاعدة فيسبوك الصلبة**: لا توجد صفحة بلا **حساب شخصي** خلفها. حتى لو أنشأتها من
Business Portfolio، لا بدّ من بروفايل شخصي يكون Admin.

### القرار: أي حساب شخصي؟

| الخيار | الحكم | السبب |
|---|---|---|
| **حسابك الشخصي الحقيقي** | ✅ **الأفضل** | قابل للاستعادة (بريد + هاتف + هوية). لو ضاع الحساب = ضاعت الصفحة |
| حساب ثانٍ «مخصّص للأخبار» | ⚠️ مقبول بشرط | فيسبوك يسمح بحساب واحد فقط لكل شخص — الحساب الثاني قد يُغلق ويأخذ الصفحة معه |
| حساب وهمي/مزيف | ⛔ **لا تفعل** | مخالف للشروط. الإغلاق يأتي بلا إنذار ويُفقد معه كل شيء |
| حساب صديق/شخص آخر | ⛔ لا | أنت لا تملك الأصل — يمكنه إخراجك في أي لحظة |

> 🎯 **القاعدة العملية**: استخدم الحساب الحقيقي الذي تملك بريده ورقم هاتفه.

### 📌 ثلاث خطوات تنجّيك من فقدان الصفحة

**١) أضف Admin ثانياً** (أهمّ خطوة على الإطلاق)
`الصفحة → Settings → Page Access → Add New` ← أضف شخصاً تثق به.
وإن لم يوجد: أنشئ بروفايل باسمك الحقيقي (بموافقة فيسبوك) واجعله Admin ثانياً.
> بلا Admin ثانٍ: حظر حسابك = نهاية القناة بصفحة واحدة.

**٢) أنشئ Business Portfolio وضمّ الصفحة إليه**
[business.facebook.com](https://business.facebook.com) ← **Accounts → Pages → Add → Claim**
> الفائدة: ملكية الصفحة تصبح مُسجَّلة في كيان منفصل عن حسابك الشخصي، ويمكن إضافة
> **System User** بتوكن لا ينتهي — وهذا أكثر استقراراً من توكن شخصي.

**٣) لا تحذف حسابك الشخصي أبداً**
حذف البروفايل = حذف الصفحات التي يديرها.

### ⚠️ الفخّ الذي يُسقِط أغلب الناس

تطبيق Meta والبروفايل **يجب أن يكونا من نفس الشخص**:

```
حساب (أ) → أنشأ التطبيق   ✅
حساب (أ) → Admin في الصفحة ✅  ⇒ يعمل بلا مشاكل

حساب (أ) → أنشأ التطبيق
حساب (ب) → Admin في الصفحة ⛔  ⇒ التوكن لا يرى الصفحة
```

**الحلّ إن كانا مختلفين**: أضف حساب (ب) كـ **Tester/Developer** في التطبيق
(`App Roles → Roles → Add People`) — أو الأسهل: أنشئ التطبيق من نفس حساب الصفحة.

> 💡 **ترتيب العمل الصحيح**: أنشئ الصفحة أولاً، ثم أنشئ التطبيق من نفس الحساب،
> ثم ولّد التوكن. لا تعكس الترتيب.

## ١) إنشاء التطبيق — مرة واحدة (٥ دقائق)

1. افتح [developers.facebook.com/apps](https://developers.facebook.com/apps) بحسابك الشخصي.
   **يجب أن تكون أنت «Admin» في الصفحة التي تريد النشر فيها.**
2. **Create App**
3. عند السؤال «What do you want your app to do?» اختر:
   → **Other** ← ثم **Business** (لا تختار Consumer ولا Gaming)
4. **App name**: `AutoNews Agent` (أي اسم) · **App contact email**: بريدك
5. **Create app** → قد يطلب كلمة سرّك، أدخلها.

### أضف المنتج المطلوب
في لوحة التطبيق: **Add Product** ← ابحث عن **Facebook Login for Business** ← **Set up**

## ١.٥) شاشة «حالات الاستخدام» — ماذا تختار؟ ⭐ الأهمّ

بعد إنشاء تطبيق **Business** تظهر شاشة:

> «حالات الاستخدام — حدّد كل حالة استخدام لتخصيص طريقة عملها وإضافة ملحقات…»

هذه الشاشة **هي التي تفتح الصلاحيات**. لو اخترت خطأً، لن تجد
`pages_manage_posts` في Graph API Explorer أبداً، وستظنّ أن المشكلة في التوكن
وأنت تدور في حلقة.

### أي واحدة تختار؟

| حالة الاستخدام في الشاشة | تصلح لنا؟ | لماذا |
|---|---|---|
| **إدارة كل شيء في صفحتك** · *Manage everything on your Page* | ✅ **اخترها** | تعطيك `pages_show_list` + `pages_read_engagement` + `pages_manage_posts` دفعةً واحدة — كل ما نحتاجه للنشر |
| تسجيل الدخول بفيسبوك للأعمال · *Facebook Login for Business* | ✅ بديل صالح | لكن يجب أن تضيف الصلاحيات **يدوياً** بعدها |
| إدارة رسائل إنستغرام · إدارة محتوى إنستغرام | ⛔ لا | للنشر على إنستغرام لا فيسبوك |
| إدارة الإعلانات · قياس الإعلانات | ⛔ لا | لا علاقة بالنشر العضوي |
| إدارة المجموعات · واتساب | ⛔ لا | أنواع نشر مختلفة تماماً |

> 🎯 **الاختيار الصحيح: «إدارة كل شيء في صفحتك»** — بنقرة واحدة تحصل على الصلاحيات
> الثلاث، ويمكنك النشر مباشرة بلا طلبات إضافية.

### الخطوات بالضبط

**١)** في شاشة «حالات الاستخدام» اضغط **«إدارة كل شيء في صفحتك»** ← **«تخصيص» (Customize)**

**٢)** ستجد قسم **«الصلاحيات»**. تأكّد من وجود:

```
pages_show_list          ✅
pages_read_engagement    ✅
pages_manage_posts       ✅   ← هذه هي صلاحية النشر
```

إن كانت إحداها ناقصة: اضغط **«إضافة»** بجانبها.

**٣)** في نفس الشاشة قد يظهر **«اتصال» / Connect** لاختيار الصفحة ←
   **اختر صفحتك** ← وافق على الصلاحيات.

> ℹ️ إن لم تظهر خطوة «الاتصال» فلا مشكلة — ربط الصفحة يحدث فعلياً في
> **Graph API Explorer** (القسم ٢)، وهناك تُختار الصفحة وتُعطى الصلاحية.

**٤)** احفظ ← **انتقل إلى القسم ٢** لتوليد التوكن.

### 🧭 خريطة الترتيب (لا تعكسها)

```
إنشاء التطبيق  →  اختيار «إدارة كل شيء في صفحتك»  →  إضافة الصلاحيات الثلاث
      →  Graph API Explorer: اختر الصفحة وولّد التوكن
      →  fb_main --token (توكن دائم)  →  GitHub Secrets  →  --check
```

### ❓ «أربط الصفحة أولاً أم أختار الحالة أولاً؟»

**الحالة أولاً، والصفحة بعدها.** السبب: الحالة تفتح **الصلاحيات**، والصلاحيات هي
التي تسمح لك باختيار الصفحة. لو ربطت الصفحة قبل إضافة الصلاحية، لن تظهر في
القائمة أصلاً.

```
حالة الاستخدام  →  الصلاحيات  →  الصفحة  →  التوكن
     (تفتح)        (تسمح)      (تُختار)    (يُولَّد)
```

### 🔁 أضفتِ التطبيق ولم تجد «حالات الاستخدام»؟

بعض الحسابات تفتح التطبيق مباشرة على **لوحة التحكّم** بدل شاشة الحالات. في هذه
الحالة: **Add Product → Facebook Login for Business**، ثم أكمل من القسم ٢
(ستضيف الصلاحيات الثلاث في Graph API Explorer مباشرةً).

## ٢) احصل على التوكن (Graph API Explorer)

1. افتح [Graph API Explorer](https://developers.facebook.com/tools/explorer/)
2. **Meta App** (أعلى يمين): اختر تطبيقك `AutoNews Agent`
3. **User or Page**: اختر **Get User Access Token**
4. **Permissions**: أضف الثلاثة (إن لم تكن مضافة تلقائياً من حالة الاستخدام):
   ```
   pages_show_list
   pages_manage_posts
   pages_read_engagement
   ```
   > 💡 إن ظهرت مضافة مسبقاً ⇒ حالتك للاستخدام صحيحة، اذهب للخطوة ٥ مباشرة.
5. **Generate Access Token** → ستفتح نافذة: **اختر صفحتك** ← **Allow** لكل الصلاحيات.
   > 🔑 **هذه الخطوة الحاسمة**: إن لم تختر الصفحة هنا، لن يظهر توكنها لاحقاً إطلاقاً.
6. انسخ التوكن (يبدأ بـ `EAA...`) — **هذا `FACEBOOK_USER_TOKEN` المؤقّت**.

### استخرج توكن الصفحة الدائم (بدّل المؤقّت)

التوكن الذي نسخته ينتهي بعد **٦٠ دقيقة**. نحوّله إلى توكن صفحة دائم:

**الطريقة الأسهل — من طرفية هذا المشروع:**

```bash
export FACEBOOK_USER_TOKEN="EAA..."
python -m autonews.fb_main --token
```

يُخرج لك مباشرة:
```
FACEBOOK_PAGE_ID=1234567890123456
FACEBOOK_PAGE_TOKEN=EAAxxxxxxxx...   ← هذا الدائم
```

**الطريقة اليدوية** (من المتصفّح، بلا أي أداة) — ثلاث خطوات:

```
١) بدّل المؤقّت بطويل الأمد (٦٠ يوماً):
   GET /oauth/access_token?grant_type=fb_exchange_token
       &client_id=APP_ID &client_secret=APP_SECRET
       &fb_exchange_token=USER_TOKEN

٢) اقرأ صفحاتك:
   GET /me/accounts?fields=id,name,access_token&access_token=LONG_TOKEN

٣) انسخ access_token الخاص بصفحتك ← هذا هو Dائم (لا ينتهي)
```

> 💡 `APP_ID` و`APP_SECRET` في: لوحة التطبيق ← **Settings → Basic**.

## ٢.٥) قراءة شاشة «معلومات رمز الوصول» ⭐

بعد توليد التوكن اضغط **ⓘ معلومات رمز الوصول** فتظهر شاشة كهذه. إليك كيف تُقرأ:

| الحقل | القيمة الشائعة | المعنى | الحكم |
|---|---|---|---|
| **النوع** | `User` | توكن **مستخدم** — مؤقّت | ⚠️ **يجب تحويله** لتوكن صفحة |
| | `Page` | توكن صفحة | ✅ هذا المطلوب |
| **انتهاء الصلاحية** | `1793545200` (بعد ساعة) | صلاحية التوكن نفسه | ⚠️ ساعة فقط |
| **انتهاء صلاحية الوصول إلى البيانات** | `1801315080` (٣ أشهر) | كم يبقى الوصول للبيانات | ℹ️ لا يعنينا |
| **النطاقات** | `pages_show_list, pages_read_engagement, pages_manage_posts` | الصلاحيات | ✅ **ممتاز — كل المطلوب موجود** |
| **صالح** | `صواب` | التوكن يعمل الآن | ✅ |

### 🎯 الخلاصة من هذه الشاشة

```
✅ الصلاحيات: كلها موجودة (السبب الوحيد الذي يهمّ)
⚠️ النوع: User  ⇒  انتهاء: بعد ساعة
```

**هذا يعني خطوة واحدة فقط ناقصة: تحويل التوكن المؤقّت إلى توكن صفحة دائم.**
لا تحتاج تعيد أي شيء آخر — الصلاحيات وحالتك للاستخدام صحيحة.

### ⚠️ لكن انتبه لعلامة تحذير واحدة

> «انتهاء الصلاحية: **خلال ساعة**» مع نوع `User` أمر طبيعي.
> المشكلة فقط إن كان **enتهاء الوصول للبيانات = `لا شيء` (never)** ومعه فشل في
> `me/accounts`. عندها يكون السبب أنك **لم تختر الصفحة** في نافذة الموافقة.

### 🔬 بدل التخمين — شخّص:

```bash
export FACEBOOK_USER_TOKEN="EAA..."     # انسخ التوكن من الشاشة
python -m autonews.fb_main --diagnose
```

يطبع لك خطوة بخطوة:

```
🔬 تشخيص التوكن
١) النوع: مستخدم
   ⚠️ توكن مستخدم = ينتهي قريباً. المطلوب توكن صفحة (لا ينتهي).
   ⏳ ينتهي: 2026-11-01 15:00 UTC
٢) الصلاحيات: pages_show_list، pages_read_engagement، pages_manage_posts
   ✅ الثلاث المطلوبة موجودة
٣) الصفحات: ✅ 1
   ✅ أخبار العراق — 1234567890123456

▶ الخطوة التالية: python -m autonews.fb_main --token
```

**وإن كانت المشكلة «لم تختر الصفحة»**، يقولها بالحرف:
```
٣) الصفحات: ⚠️ القائمة فارغة
   السبب الأشهر: لم تختر صفحتك عند الموافقة على الصلاحيات.
   الحلّ: Graph API Explorer ← Generate Access Token ←
   في النافذة اضغط على اسم الصفحة ← Allow لكل صلاحية.
```

### 🔁 تحويل التوكن (٣٠ ثانية)

```bash
python -m autonews.fb_main --token
```

يُخرج:
```
FACEBOOK_PAGE_ID=1234567890123456
FACEBOOK_PAGE_TOKEN=EAAxxxxxxxx...   ← هذا الدائم، ضعه في Secrets
```

> 🎁 **لماذا لا يظهر في تصحيح أخطاء (Debug) النوع `Page`؟**
> لأن توكن الصفحة الناتج من `me/accounts` يُعرَض في تصحيح الأخطاء **أحياناً**
> كـ `User` بسبب طريقة توليده، لكنه في الحقيقة **لا ينتهي**. الفيصل عملياً:
> `expires_at` غائب ⇒ دائم ✅.

## ٣) معرّف الصفحة — من أين؟

ثلاث طرق، أي واحدة تعمل:

| الطريقة | كيف |
|---|---|
| **الأسهل** | `python -m autonews.fb_main --token` يطبعه لك |
| من الصفحة | الصفحة ← **About** ← **Page transparency** ← **Page ID** |
| من المنشورات | افتح أي منشور ← الرابط فيه أرقام ← الجزء الأول = Page ID |

> ⚠️ **لا تخلط** بين `page_id` (أرقام) و`username` (نصّ). الناشر هنا يحتاج **الأرقام**.

## ٣.٥) إضافة الصفحة — أربع معانٍ محتملة

كلمة «أضيف الصفحة» تُستخدم لأربعة أشياء مختلفة في Meta. اختر ما يخصّك:

| # | ما تريد إضافته | أين | مطلوب للنشر؟ |
|---|---|---|---|
| **أ** | **الصفحة نفسها للتطبيق** (كي يراها التوكن) | Graph API Explorer ← نافذة الموافقة | ✅ **نعم — هذه هي** |
| ب | الصفحة إلى **Business Portfolio** | business.facebook.com | ⚠️ مستحسن (نظامية أكثر) |
| ج | الصفحة إلى **حالة الاستخدام** | App Dashboard ← حالة الاستخدام ← Connect | ⚠️ بديل عن (أ) |
| د | **رابط/إعداد** الصفحة في المشروع | زرّ «📘 ربط صفحة فيسبوك» | ✅ لتشغيله |

### (أ) الطريقة الصحيحة — من Graph API Explorer ⭐

```
1. developers.facebook.com/tools/explorer
2. Meta App → اختر: autonews-agent
3. User or Page → Get User Access Token
4. Permissions → أضف الثلاث + اضغط Generate Access Token
5. 🔴 تفتح نافذة فيها أسماء صفحاتك:
      ☑ اختر صفحتك  ← اضغط «تعديل»/Edit على الصلاحيات
      ☑ Allow على pages_manage_posts
6. انسخ التوكن
```

> ⚠️ **إن لم تظهر صفحتك في النافذة إطلاقاً**، فالمشكلة في **حالة الاستخدام**:
> اذهب إلى App Dashboard ← حالة الاستخدام ← «إدارة كل شيء في صفحتك» ←
> تحقّق من قسم **Connect/اتصال** واضغطه لتربط الصفحة.

### (د) من البوت — بلا تعديل ملفات ⭐

عندك زرّ جديد:

```
📊 الإدارة ← 📘 ربط صفحة فيسبوك ← ✏️ أضف معرّف الصفحة ← أرسل الأرقام
```

يحفظ المعرّف داخل `channels.yml` (`extra.ENV_PAGE_ID`) تلقائياً.
**ولاحظ**: البوت **لا يطلب منك التوكن** — عمداً. التوكن خاصّتك، ولا يُمرَّر في
تيليجرام. يبقى في GitHub Secrets وحده.

أو من الطرفية:

```bash
python -m autonews.fb_main --token                 # يُخرج المعرّف + التوكن
python -m autonews.fb_main --save-page 123456789   # يحفظ المعرّف فقط
```

| المعلومة | أين تُحفظ | السبب |
|---|---|---|
| `page_id` (أرقام) | `config/channels.yml` — أوتوماتيك | ليس سرّاً (رقم عام) |
| `page_token` | GitHub Secrets | سرّ — يمنح نشراً كاملاً |

## ٣.٧) من أين أجيب «رموزها»؟ — ثلاث قطع مختلفة ⭐

«رموز الصفحة» تُطلق على ثلاثة أشياء، وكل واحد له مكان مختلف. هذا الجدول يحسم الالتباس:

| # | الرمز | أين تجده | يدوم؟ |
|---|---|---|---|
| **١** | **التوكن المؤقّت** (`EAA…`) | Graph API Explorer ← **Generate Access Token** | ⏱ **ساعة** |
| **٢** | **توكن الصفحة الدائم** | `python -m autonews.fb_main --token` | ♾ **لا ينتهي** (إن مدّدت أولاً) |
| **٣** | **App ID + App Secret** | App Dashboard ← **Settings → Basic** | ثابت (ليس توكن) |

### ١) التوكن المؤقّت — من Graph API Explorer

بعد اختيار صفحتك والموافقة على الصلاحيات، أعلى الصفحة يوجد صندوق
**«Access Token»** ← اضغط **نسخ**. هذا هو `EAA…`

### ٢) توكن الصفحة — يُولَّد لا يُنسخ

لا يوجد زرّ اسمه «Page Token» في Graph API Explorer. يُستخرج بأمر واحد:

```bash
export FACEBOOK_USER_TOKEN="EAA..."     # المؤقّت من الخطوة ١
python -m autonews.fb_main --token
```

**لكن قبل ذلك** — انسخ App ID وApp Secret ليمدّ التوكن تلقائياً:

### ٣) App ID و App Secret — من لوحة التطبيق

```
developers.facebook.com/apps
  → اختر تطبيقك: autonews-agent
  → Settings → Basic
  → App ID            (أرقام، مثل APP_ID_هنا)
  → App Secret        ← اضغط «Show» وأدخل كلمة سرّك
```

> ⚠️ **App Secret سرّ خطير** — لا يُرفع في المستودع ولا يُرسل في محادثة.
> استخدمه في طرفيتك فقط (أو GitHub Secrets).

### 🚀 الأمر الكامل — توكن لا ينتهي

```bash
export FACEBOOK_USER_TOKEN="EAA..."            # من Graph API Explorer
export FACEBOOK_APP_ID="APP_ID_هنا"      # من Settings → Basic
export FACEBOOK_APP_SECRET="xxxxx"             # من Settings → Basic

python -m autonews.fb_main --token
```

يُخرج:

```
🔑 استخراج رموز الصفحة
──────────────────────────────────────────────────
١) توكن المستخدم: ✅ مُدَّ إلى 60 يوماً
٢) الصفحة: ✅ أخبار العراق (1234567890123456)

══════════════════════════════════════════════════
FACEBOOK_PAGE_ID=1234567890123456
FACEBOOK_PAGE_TOKEN=EAAxxxxxxxx...        ← هذا الدائم
══════════════════════════════════════════════════
```

### ⚠️ الترتيب مهمّ جداً — وهذا سبب «التوكن ينتهي دائماً»

```
توكن قصير (ساعة)  →  توكن صفحة  ⇒  ينتهي بعد ساعة ❌
توكن طويل (٦٠ يوماً)  →  توكن صفحة  ⇒  لا ينتهي ♾ ✅
```

**الخلاصة**: التمديد يجب أن يحدث **قبل** استخراج توكن الصفحة. أداة `--token`
تفعل ذلك تلقائياً إن وجدت `APP_ID` و`APP_SECRET`. وإن لم تجدهما، تحذّرك صراحةً:

```
١) توكن المستخدم: ⚠️ لم أُمِدّه (لا APP_ID ولا APP_SECRET)
   توكن الصفحة الناتج سينتهي معه (ساعة).
```

### 🕐 ومع ذلك — «انتهاء الوصول للبيانات بعد ٣ أشهر» ما يهمّ

في شاشة معلومات الرمز يظهر سطران:

| السطر | معناه | يهمّنا؟ |
|---|---|---|
| انتهاء الصلاحية | صلاحية **التوكن نفسه** | ✅ انتبه له |
| انتهاء صلاحية الوصول إلى البيانات | كم يبقى **المستخدم نفسه** مصرّحاً | ❌ لا — التوكن الدائم يتجاوزه |

فإذا كان **انتهاء الصلاحية = لا شيء (Never)** فأنت في الوضع الصحيح تماماً.

### 🅱 بديل: System User (الأكثر استقراراً للمشاريع)

إن ضمّمت الصفحة إلى **Business Portfolio**:

```
business.facebook.com → Settings → Users → System Users → Add
  → اختر النظام → Add Assets → Pages → صفحتك → Full control
  → Generate New Token → اختر تطبيقك + pages_manage_posts
  → التوكن لا ينتهي ولا يرتبط بحسابك الشخصي
```

> هذا الأقوى على المدى الطويل: لو تعطّل حسابك الشخصي، يبقى النشر شغّالاً.

## ٤) الأسرار في GitHub — سرّان فقط

`Settings` → `Secrets and variables` → `Actions` → **New repository secret**

| الاسم | القيمة | إجباري |
|---|---|---|
| `FACEBOOK_PAGE_ID` | `1234567890123456` | ✅ |
| `FACEBOOK_PAGE_TOKEN` | توكن الصفحة **الدائم** (`EAA…`) | ✅ |
| `FACEBOOK_USER_TOKEN` | التوكن المؤقّت | ❌ بديل فقط |

> 🚫 **لا تضع أي توكن في `config/`** — `channels.yml` مرفوع للمستودع.
> أسماء المتغيّرات موجودة فيه، أما **القيم** فتبقى في Secrets.

## ٤.٥) الحدّ الأدنى: **سرّ واحد فقط** ⭐

إن كان عندك توكن صفحة دائم، فأنت لا تحتاج شيئاً آخر. **التوكن يعرف صفحته.**

```
python -m autonews.fb_main --autofill
```

بعد `export FACEBOOK_PAGE_TOKEN="EAA..."` يُخرج:

```
📘 ضبط فيسبوك من التوكن
──────────────────────────────────────────────────
✅ الصفحة: أخبار العراق (1234567890123456)
♾ لا ينتهي — توكن دائم ✅
✅ حُفظ المعرّف تلقائياً في channels.yml

▶ جاهز. الباقي: أضف FACEBOOK_PAGE_TOKEN في GitHub Secrets فقط.
```

### ما تحتاجه فعلاً — جدول نهائي

| العنصر | عندك؟ | إجباري؟ | أين يوضع |
|---|---|---|---|
| **`FACEBOOK_PAGE_TOKEN`** (دائم) | ✅ | ✅ **الإجباري الوحيد** | GitHub Secrets |
| `FACEBOOK_PAGE_ID` | يُستخرج تلقائياً | ❌ | لا تحتاجه أصلاً |
| `FACEBOOK_APP_ID` / `App Secret` | | ❌ | للتوليد فقط، لا للتشغيل |
| `FACEBOOK_USER_TOKEN` | | ❌ | للتوليد فقط، ينتهي بعد ساعة |

> 🎯 **الخلاصة**: سرّ واحد في GitHub Secrets = فيسبوك شغّال.
> ولو حتى **لم** تحفظ المعرّف في الملف: النظام يقرأه من `extra.ENV_PAGE_ID`
> ثم من البيئة. لكن `--autofill` أنظف لأنه يثبّته في المستودع مرة واحدة.

### قبل أن تبدأ — تأكّد من ثلاث نقاط

| # | الفحص | كيف |
|---|---|---|
| ١ | توكن **صفحة** لا مستخدم | `--autofill` يقول «لا ينتهي ✅» |
| ٢ | صفحة **فيسبوك** لا بروفايل | النشر في البروفايل غير مسموح عبر API |
| ٣ | ***أنت Admin*** في الصفحة | وإلّا النشر يفشل بـ `(#200)` |

### الحدّ الأدنى مطلقاً — مسار من ٤ خطوات

```bash
# ١) ضع التوكن الذي عندك
export FACEBOOK_PAGE_TOKEN="EAA..."

# ٢) تحقّق واحفظ المعرّف تلقائياً
python -m autonews.fb_main --autofill

# ٣) اختبار نشر حقيقي
python -m autonews.fb_main --test --live

# ٤) GitHub Secrets: أضف FACEBOOK_PAGE_TOKEN فقط
```

انتهى. لا App ID، لا App Secret، لا توكن مستخدم.

## ٦) أخطاء شائعة وحلولها

| الرسالة | السبب الحقيقي | الحلّ |
|---|---|---|
| `(#200) Permissions error` | التوكن بلا `pages_manage_posts`، أو أنت لست Admin | أعد توليد التوكن واختر الصلاحية + تأكّد أنك Admin في الصفحة |
| `Error validating access token` | توكن منتهٍ (٦٠ دقيقة) | استخدم توكن الصفحة **الدائم** |
| `(#100) Tried accessing nonexistent field` | `page_id` خطأ أو `username` بدل رقم | `--token` يطبعه صحيحاً |
| `Unsupported post request` | تنشر في **بروفايل** لا صفحة | فيسبوك لا يسمح بالنشر في البروفايل عبر API — يجب صفحة |
| `(#368) Temporarily blocked` | تكرار/إساءة | النظام يتعامل معها (انتظار ٢٠ ثانية وإعادة) |
| الصورة تُنشر بلا نصّ | تعذّر `/photos` فانتقل للنصّ | طبيعي — يتحوّل تلقائياً إلى `/feed` |

## ٧) كيف يتعامل النظام مع فيسبوك تلقائياً؟

| الحالة | ما يفعله |
|---|---|
| صورة موجودة | ينشر عبر `/photos` (أكبر وضوحاً في التغذية) |
| فشل الصورة | ينشر النصّ عبر `/feed` — **لا يفشل المنشور كله** |
| `page_access_token` موجود | يستخدمه مباشرة |
| `user_access_token` فقط | يستخرج توكن الصفحة تلقائياً (`/me/accounts`) |
| حدّ المعدّل (code 4 · 17 · 32 · 613) | ينتظر ٢٠ ثانية ويعيد مرّة واحدة |
| بصمة الملكية | `تابعنا على فيسبوك: اسم_صفحتك` + علامة على الصورة |

## ٨) هل تحتاج مراجعة التطبيق (App Review)؟

**لا.** ما دام التطبيق في وضع **Development** وأنت تنشر في صفحتك التي تُديرها،
فالأذونات تعمل لمالكي التطبيق والمختبرين بلا مراجعة.

تحتاج مراجعة **فقط** إذا:
- تريد النشر في صفحات **لا تملكها**، أو
- جعلت التطبيق **Live** لمستخدمين خارجيين.

لتشغيلك الشخصي: اتركه **Development** — وهذا آمن تماماً ومجاني.

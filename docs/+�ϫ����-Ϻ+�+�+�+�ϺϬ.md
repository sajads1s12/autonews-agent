# 📡 مخطط القنوات — قناة لكل قطاع

## السؤال: هل أحتاج قناة لكل شي؟

**نعم، لكن بالتدريج.** التقسيم المبكر يوزّع جمهورك على قنوات صامتة.
التقسيم المتأخر يزعج من يريد الأنمي فقط بأخبار السياسة.

---

## 🗺 المخطط الموصى به

```
┌─────────────────────────────────────────────────────────────┐
│                    بوت واحد (نفس التوكن)                     │
└─────────────────────────────────────────────────────────────┘
        │                  │                  │
   ┌────▼────┐      ┌──────▼──────┐    ┌─────▼──────┐
   │ tg_main │      │  tg_anime   │    │ tg_sports  │
   │ الأخبار │      │   الأنمي    │    │  الرياضة   │
   ├─────────┤      ├─────────────┤    ├────────────┤
   │ كل شي   │      │ أنمي فقط    │    │ رياضة فقط  │
   │ إلا أنمي│      │             │    │            │
   └─────────┘      └─────────────┘    └────────────┘
       ▲                   ▲                  ▲
       │                   │                  │
  بوّابة النتائج      سياسة الإعلان      سياسة المباريات
  (لا حادث خام)      (الإعلان = خبر)     (النتيجة = خبر)
```

---

## 🔑 كل قناة = سرّ منفصل

| القناة | السرّ | لماذا منفصل؟ |
|---|---|---|
| `tg_main` | `TELEGRAM_CHAT_ID` | — |
| `tg_anime` | `TELEGRAM_ANIME_CHAT_ID` | قد تكون على **حساب أو بوت آخر** |
| `tg_sports` | `TELEGRAM_SPORTS_CHAT_ID` | قد يديرها فريق مختلف |
| `tg_tech` | `TELEGRAM_TECH_CHAT_ID` | موجودة أصلاً |

**البوت** يمكن أن يكون واحداً (`TELEGRAM_BOT_TOKEN`) — يمكن إضافته مشرفاً في كل القنوات.
لكن **المعرّف منفصل** لكل قناة.

---

## 🚫 الفصل بـ `exclude_tags` (لا بالنسخ)

```yaml
- id: tg_main
  tags: []                      # عامة
  exclude_tags: ["أنمي"]        # 🚫 لا تستقبل الأنمي

- id: tg_anime
  tags: ["أنمي"]                # ✅ الأنمي فقط
```

### لماذا لا ننشر في الاثنين؟

| المشكلة | التفصيل |
|---|---|
| تكرار مزعج | من يتابع القناتين يرى نفس المنشور مرّتين |
| إحراج تحريري | خبر أنمي في قناة إخبارية أمنية يُضعف الثقة |
| خلط في القياس | إحصاءات UTM تصير مضلّلة |

**الحل الصحيح**: استثناء، لا نسخ. والقطاعية تكون **أعمق** لا أصغر:
- العامة: الخبر كما هو
- القطاعية: + تقويم المواسم · جداول · متابعة عمل واحد · ترتيب أسبوعي

---

## 📊 متى تفتح قناة جديدة؟

| الشرط | الحدّ |
|---|---|
| أخبار القطاع يومياً | **≥ ٣** |
| طلبات من الجمهور | متكرّرة |
| محتوى متخصّص إضافي | موجود (لا نسخ) |

أقل من ذلك ⇒ القناة العامة أفضل مكاناً.

## 🛠 الأوامر

```bash
# ١) اعرض الوضع الحالي
python -m autonews.channels_main

# ٢) هل كل قناة جاهزة؟ (فحص حقيقي عبر تيليجرام)
python -m autonews.channels_main --check

# ٣) أضف قناة جديدة (جاهزة بالكامل، معطّلة)
python -m autonews.channels_main --add tg_sports \
    --name "قناة الرياضة" --tags رياضة --sector الرياضة

# ٤) اربطها واختبرها
python -m autonews.chatid --chat @my_sports --test --save tg_sports

# ٥) فعّلها في channels.yml:  enabled: true  ثم ادفع
```

- [ ] كل قناة لها سرّها الخاص في GitHub Secrets

- [ ] القناة القطاعية فيها `tags` صريحة

## 🎛 الربط من البوت — لا من الملفات

القنوات السبع **مجهّزة مسبقاً** في `config/channels.yml`. المتبقّي عليك خطوة واحدة
لكل قناة: **معرّفها**. وتُدخله من داخل تيليجرام:

1. افتح بوت الإعداد على هاتفك، أرسل `/start`.
2. اضغط على القناة (مثل «⬜ 🎬 الأنمي»).
3. البوت يطلب المعرّف → أرسل `@username` أو `-100…` أو رابط دعوة.
4. البوت يتحقّق فعلياً من تيليجرام (موجودة؟ البوت أدمن؟) ثم ✅ أو ❌ مع الحل.

**بلا حاسوب، بلا محرّر نصوص، بلا لمس أي ملف.**

| الأمر | الوظيفة |
|---|---|
| `python -m autonews.setup_main --status` | جدول: كم قناة جاهزة من ٧ |
| `python -m autonews.setup_main --panel` | إعادة إرسال لوحة الأزرار |
| `python -m autonews.setup_main --poll` | التقاط الضغطات (مجدوَل كل ٥ دقائق) |
| `python -m autonews.setup_main --auto` | فحص كل القنوات ذاتياً ثم تقرير |

المعرّفات تُحفظ في `state/channels_setup.json` (**معرّفات فقط، لا أسرار**)،
وأولوية القراءة: الملف ← `extra.ENV_*` ← متغيّر البيئة.

> ⚠️ **أمان**: البوت يقبل الأوامر من `TELEGRAM_ADMIN_CHAT_ID` و`SETUP_ALLOWED_USERS` فقط.
> أي شخص آخر يُرفض — وإذا لم يُضبط أي منهما، يرفض البوت **الجميع** (فشل مُغلَق).

# 🔐 أمان الأسرار — ماذا تفعل إن انكشف مفتاح

## القاعدة الأولى

**أي سرّ يُكتب في محادثة أو ملف = سرّ محروق.** لا يهمّ إن حُذف لاحقاً — يُفترض
أنه انكشف ويجب **إبطاله (Rotate)** لا حذفه فقط.

| السرّ | خطره إن انكشف | الإجراء |
|---|---|---|
| **Facebook App Secret** | يمكن توليد توكنات بلا حسابك، وتجاوز حدود الطلبات | إعادة التوليد فوراً |
| **Facebook Page Token** | نشر/حذف منشورات بصفحتك | إعادة التوليد |
| **Telegram Bot Token** | التحكّم الكامل بالبوت | `/revoke` من BotFather |
| **Gemini API Key** | استهلاك حصتك أو تكلفتها | حذف المفتاح من AI Studio |
| **App Secret معروف + توكن** | أخطر تركيبة: وصول كامل | إبطال الاثنين |

---

## ١) إبطال Facebook App Secret (دقيقة واحدة)

```
developers.facebook.com/apps/APP_ID_هنا/settings/basic/
  → App Secret → «Reset» → Confirm
  → انسخ الجديد
```

بعد الإبطال:
- ✅ التوكنات المولّدة **سابقاً** تبقى تعمل (لأنها توكنات صفحة مستقلة).
- ⚠️ لكن أي توكن يُولَّد بالسرّ القديم يتوقّف.
- 🔁 إذا كنت ستستخدم `--token` لاحقاً، استخدم السرّ الجديد.

> 💡 **الخبر الجيد**: `App Secret` **لا يُستخدم في التشغيل اليومي** لهذا المشروع.
> النشر يحتاج `FACEBOOK_PAGE_TOKEN` فقط. فإبطال السرّ **لا يوقف قناتك**.

---

## ٢) هل تحتاج إبطال توكن الصفحة أيضاً؟

| الحالة | الإجراء |
|---|---|
| التوكن **لم** يُشارَك في أي محادثة/ملف | ✅ اتركه — غيّر السرّ فقط |
| التوكن ظهر في نصّ أو لقطة شاشة أو محادثة | 🔁 أعد توليده وأبدله في Secrets |

---

## ٣) أين تُحفظ الأسرار في هذا المشروع؟ (الخريطة الكاملة)

| الملف/المكان | يُرفع للمستودع؟ | ما فيه |
|---|---|---|
| `config/channels.yml` | ✅ نعم | **أسماء** متغيّرات فقط (`TELEGRAM_CHAT_ID`) — لا قيم |
| `config/settings.yml` | ✅ نعم | مصادر وأرقام — لا أسرار |
| `state/*.json` · `logs/*` | ⛔ **لا** (مستثناة في `.gitignore`) | تُحفظ في المستودع الخاص `autonews-state` فقط |
| `GitHub Secrets` | ⛔ لا | التوكنات والمفاتيح الحقيقية |
| `.env` | ⛔ **ممنوع** (في `.gitignore`) | للتطوير المحلي فقط |

## ٤) حماية تلقائية في المشروع

```bash
bash scripts/check_secrets.sh     # يفحص ٦ أنماط أسرار معروفة
```

ويعمل **تلقائياً في CI عند كل push** — يمنع رفع:
- `EAA…` توكن فيسبوك
- `123456789:AA…` توكن بوت تيليجرام
- `AIza…` مفتاح Gemini
- `32 حرفاً hex` (شكل App Secret)
- `ghp_…` توكن GitHub
- `xox…` توكن Slack

### فعّل حماية GitHub الإضافية (مرّة واحدة)

```
Settings → Code security and analysis
  ☑ Secret scanning
  ☑ Push protection          ← يمنع الدفع نفسه إن كان فيه سرّ
  ☑ Dependabot alerts
```

## ٥) قاعدة عملية للتعامل معي ومع أي أداة

| ما تفعله | الحكم |
|---|---|
| تنسخ مفتاحاً في محادثة لطلب مساعدة | ⚠️ افترض أنه انكشف → أبطله بعد الانتهاء |
| تضع المفاتيح في GitHub Secrets | ✅ الصحيح |
| تنفّذ `export TOKEN=...` في طرفية مؤقّتة | ✅ مقبول (لا يُحفظ) |
| تضع مفتاحاً في `config/` | ⛔ خطير — الملف مرفوع |
| ترسل توكن في محادثة تيليجرام (حتى لبوتك) | ⛔ خطير — التوكن **لا** يُرسَل تلقائياً أبداً |

> **الملاحظة الأخطر**: في تيليجرام، الرسائل تبقى في سجلّ الجهاز والنسخ الاحتياطي
> والسحابة. لذلك بوت الإعداد في هذا المشروع **لا يطلب التوكن أبداً** — يطلب
> المعرّفات فقط (وهي أرقام عامة).

## ٦) قائمة تحقّق بعد أي تسريب

- [ ] أبطلت السرّ (Reset / Revoke) لا حذفته فقط
- [ ] ولّدت سرّاً جديداً ووضعته في GitHub Secrets
- [ ] حذفت السرّ من أي ملف محلي (`git grep` للتأكد)
- [ ] شغّلت `bash scripts/check_secrets.sh`
- [ ] `git log -S "السرّ"` للتأكد أنه لم يدخل أي commit
- [ ] راجعت `Actions` — لا تشغيلات غريبة

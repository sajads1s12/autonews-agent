# 📊 مركز الإدارة — كل شيء من البوت

زرّ واحد في اللوحة الرئيسية (**«📊 الإدارة»**) يفتح أربع أدوات:

```
📊 مركز الإدارة
  ├─ 📊 الإحصاءات      ← من نشر ماذا ومتى (وأين المشكلة)
  ├─ 🏷 وسوم القناة     ← أي وسم يدخل أي قناة (بأزرار)
  ├─ ➕ قناة جديدة      ← اسم + وسوم → جاهزة فوراً
  └─ 📡 مصدر جديد       ← رابط RSS → يُختبر الآن → يُضاف
```

---

## 📊 ١) الإحصاءات

لا خدمة تحليلات خارجية — كل رقم من `state/state.json` (محلي ومجّاني).

```
📊 إحصاءات النشر
اليوم: 10 · هذا الأسبوع: 10 · الإجمالي: 10
⏰ أنشط ساعة عندك: 14:00
🕒 آخر ٢٤ ساعة: ▁▁▁▁▁▁▁▁▁▁▁▁▁▁█▁▁▁▁▁▁▁▁▁

✅ 📰 الأخبار العامة — اليوم 4 · الأسبوع 4 · الكل 4
   وزير الداخلية يوجّه بإنهاء الدعاوى… · قبل 40 دقيقة
⬜ 🎬 الأنمي — لم تنشر بعد

📡 مصادر تعمل: 28 · ميتة: 0
👁 تنتظر موافقتك: 0 · 🕒 مؤجّلة: 0
```

**الأيقونات دقيقة**:

| الأيقونة | المعنى |
|---|---|
| ⬜ | لم تنشر شيئاً — إعداد خاطئ أو قناة غير مربوطة |
| 😴 | نشرت سابقاً لكن ليس اليوم |
| ✅ | نشرت اليوم |
| 🚨 | **صامتة أكثر من ٤٨ ساعة** — عطل خفي يجب أن تراه |

**التوصيات تُستخرج من أرقامك**، لا نصائح عامة:
- «أنشط نشر بين 12:00 و17:00 — ضع ساعات الهدوء خارجها»
- «٢ قناة لم تنشر شيئاً — اربطها أو تحقّق من وسومها»
- «٣ منشورات تنتظرك — التراكم يُبطئ النشر، جرّب النمط الذكي»

```bash
python -m autonews.stats_main            # نفس العرض في الطرفية
python -m autonews.stats_main --advice   # التوصيات فقط
python -m autonews.stats_main --json     # لسكربت آخر
```

## 🏷 ٢) محرّر الوسوم

**المشكلة**: الوسم يحيا في `channels.yml`، وتعديله يحتاج حاسوباً.
**الحل**: كل وسم زرّ. ✅ = مفعّل (اضغطه ليُحذف) · ➕ = متاح (اضغطه ليُضاف).

```
🏷 وسوم 💻 التقنية
✅ تقنية، علوم، اتصالات

[✅ تقنية]      [✅ علوم]
[✅ اتصالات]    [➕ رياضة (tg_sports)]
[➕ اقتصاد]     [✏️ وسم جديد (أكتبه)]
```

**تحذيرات ذكية** بعد كل تعديل — لأن الوسم قد يبدو صحيحاً ويكسر الفصل:

| التحذير | السبب |
|---|---|
| «`fb_page` عامة (بلا وسوم) — ستستقبل هذه الوسوم أيضاً» | قناة بلا وسوم = كل شيء ⇒ الفصل وهمي |
| «🔁 تشابه مع `tg_sports`: رياضة» | نفس الخبر سيُنشر في الاثنتين |
| «🚫 `tg_main` تستثني: أنمي» | وسم مستثنى في قناة أخرى |

> التعديل **نصّي** لا YAML→YAML: تعليقاتك العربية تبقى حرفياً، والملف يُتحقّق
> من صلاحيته قبل الحفظ — وإن فشل التعديل يُلغى ولا يتلف شيء.

---

## ➕ ٣) قناة جديدة

أرسل سطراً واحداً:

```
tg_crypto | قناة العملات | عملات, بيتكوين
   ↑            ↑              ↑
المعرّف       الاسم          الوسوم (اختياري)
```

فيُكتب بلوك كامل جاهز: أسلوب · حدّ أحرف · بصمة ملكية · سرّ `TELEGRAM_CRYPTO_CHAT_ID`
· `flash_priority` — ثم زرّ **«🔗 اربطها»** مباشرة لتدخل المعرّف.

---

## 📡 ٤) مصدر جديد

أرسل رابط RSS:

```
https://site.com/rss | اسم الموقع | تقنية
```

**الاختبار يحدث قبل الإضافة**: نجلب ٥ أخبار فعلياً ونتحقّق من العنوان وعدد
الأخبار الحديثة. رابط ميت أو صفحة HTML عادية ⇒ **لا يُضاف**، مع رسالة واضحة.

```
✅ أُضيف المصدر · shafaq_ar
✅ شفق نيوز
25 خبراً · 25 حديث
مثال: يتناول جولة الزيدي الإقليمية…

سيُسحب منه في التشغيل القادم.
```

> ضمانة مهمة: ملف `settings.yml` لا يتغيّر إطلاقاً عند الفشل، ويُتحقّق من
> صلاحيته كـ YAML قبل الحفظ.

## كل ما سبق آمن للمشاركة

| الملف | ما فيه | خطر تسريب؟ |
|---|---|---|
| `config/channels.yml` | بنية القنوات + البصمات | ✅ لا |
| `config/settings.yml` | المصادر | ✅ لا |
| `state/control.json` | تحكّم + طابور | ✅ لا |
| `state/channels_setup.json` | معرّفات + بصمات | ✅ لا |

الأسرار تبقى في GitHub Secrets فقط.

# 🛡 بوابة النشر بلا موافقات + 🖋 بصمة الملكية

## ١) النشر الآلي مع بوابة ثقة

لا توجد موافقات بشرية أو طابور انتظار للنشر. كل خبر يمرّ بفحص الجودة والمصدر:

- المصدر الرسمي المعرّف بـ `official: true` يمكنه الوقوف منفرداً.
- الخبر غير الرسمي يحتاج تغطية مستقلة من ناشر مختلف بعنوان متوافق.
- الخبر منخفض الجودة أو الاحتياطي أو الحساس أو بلا رابط مصدر يُستبعد نهائياً.
- الإعدادات القديمة لأنماط المراجعة لا تغيّر هذه السياسة.

هذا يختلف عن النشر العشوائي: الحالات غير المؤكدة تُرفض، ولا تنتظر ضغطة موافقة.

## ٢) ساعات الهدوء — «يُؤجَّل لا يُلغى»

```
٢٣:٠٠ ─────────── ٠٦:٠٠
   🌙 مؤجّل            ☀️ نشر
```

خبر جاء ٠٣:٠٠ لا يُحذف ولا يُنشر في وجه الناس نائمين — يبقى في الطابور
ويُنشر ٠٦:٠١ تلقائياً. هذا يحفظ سرعة النظام بلا إزعاج.

## ٣) بصمة الملكية — ٣ طبقات

### الطبقة ١: التوقيع النصّي

```
🗞 عنوان الخبر

نصّ الخبر…

📡 @your_channel        ← يراها كل قارئ
```

على X: `via @your_channel` · على فيسبوك: `تابعنا على فيسبوك: your_channel`

### الطبقة ٢: العلامة على الصورة

شريط داكن شبه شفّاف في زاوية الصورة، بخطّ عربي **متّصل** (لا حروف مفكّكة):

```
┌──────────────────────────────┐
│                              │
│         صورة الخبر           │
│                              │
│              ┌─────────────┐ │
│              │ @your_channel│ │
│              └─────────────┘ │
└──────────────────────────────┘
```

تُرسم بالعربية الصحيحة عبر `arabic_text.py` (تشكيل + ترتيب بصري)، بلا أي مكتبة خارجية.

### الطبقة ٣: العلامة الخفيّة

اسم قناتك يُرمَّز بمحارف **صفرية العرض** (`U+200B`, `U+200C`, `U+200D`, `U+2060`)
في نهاية المنشور. لا يراها إنسان، لكنها:

- ✅ تنتقل مع **النسخ واللصق** (ليست صورة ولا رابطاً).
- ✅ تُقرأ بأمر واحد: `python -m autonews.brand_main --prove "النصّ"`
- ⛔ لا تُستخدام على X (حدّ ٢٨٠ حرفاً — نحفظ المساحة للنصّ).

## ٤) الأوامر

```bash
python -m autonews.brand_main --show                  # حالة البصمة لكل قناة
python -m autonews.brand_main --set tg_anime --handle anime_iq
python -m autonews.brand_main --preview tg_anime      # منشور + صورة نموذجية
python -m autonews.brand_main --prove "النصّ المشكوك"  # لمن تعود؟
```

## ٥) من البوت (بلا حاسوب)

```
🎛 لوحة التحكّم
  ├─ ⏸ إيقاف القناة / ▶️ تشغيلها
  ├─ 🌙 ساعات هدوء 23→06 / ☀️ إلغاء
  └─ 🖋 ضبط البصمة → أرسل @اسم_قناتك
```

الأزرار القديمة للمراجعة لا تنشئ موافقات ولا تنشر عناصر الطابور القديمة؛
أي عنصر موافقة قديم لا يمكن نشره من واجهة البوت.

## ٦) أين تُحفظ الحالة؟

| الملف | المحتوى | آمن للمشاركة؟ |
|---|---|---|
| `state/control.json` | إيقاف · ساعات الهدوء · طابور التأجيل | ✅ لا أسرار |
| `state/channels_setup.json` | معرّفات القنوات + البصمات | ✅ لا أسرار |
| `config/channels.yml` | كتلة `branding` لكل قناة | ✅ لا أسرار |

الأسرار (`TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEYS`) تبقى في GitHub Secrets فقط.

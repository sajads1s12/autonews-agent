## 🎯 الطريقة (٣ طبقات فقط لكل قطاع)

```
١) كاشف     verticals/<name>.py   → هل الخبر لهذا القطاع؟ وما نوعه؟
٢) مفردات   (أسماء/مصطلحات/أحداث) → تصنيف أدقّ بلا AI
٣) سياسة    publish_policy        → القطاع يحدّد متى يُنشر، لا الأخبار
```

كل ما تبقّى (سحب، ترجمة، UTM، لوحة، حفظ، تكرار، تنبيهات) **يعمل تلقائياً**.

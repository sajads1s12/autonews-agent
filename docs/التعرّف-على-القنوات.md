# 🧠 التعرّف التلقائي على القنوات — اربط بالاسم فقط

## الفكرة في سطر

> تربط قناة اسمها «أخبار الأنمي والمانغا» ← النظام يعرف أنها أنمي، ويضبط
> وسومها ومصادرها، ويبدأ ينشر فيها أخبار أنمي. بلا إعداد.

---

## ١) الطريقة الأسرع — زرّ واحد في البوت

```
🔧 الإدارة  →  🧠 اربط بالاسم
```

أرسل رسالة واحدة بهذا الشكل:

```
-1001234567890 | أخبار الأنمي والمانغا
```

**ما يحدث تلقائياً:**

| الخطوة | النتيجة |
|---|---|
| ١ · تصحيح المعرّف | `6444047765` ← `-1006444047765` تلقائياً |
| ٢ · التحقّق | البوت يسأل تيليجرام: هل أنا مشرف؟ |
| ٣ · التعرّف على القطاع | من الاسم: أنمي 🎌 |
| ٤ · ضبط الوسوم | `أنمي` و `مانغا` |
| ٥ · ربط المصادر | ٤ مصادر أنمي حقيقية |
| ٦ · إنشاء القناة | `tg_akhbar_alanmy_walm` إن لم تكن موجودة |

**الردّ الذي يصلك:**

```
🎉 تمّ الربط

القناة: أخبار الأنمي والمانغا
المعرّف: -1009999999999
🆕 أُنشئت قناة جديدة: tg_akhbar_alanmy_walm

🎌 عرفت القطاع: أنمي ومانغا
• الوسوم: أنمي, مانغا
• المصادر: myanimelist_news, gnews_anime_ar, animecorner, gnews_anime_new
```

> 💡 الربط العادي (زرّ القناة) يعمل أيضاً — ويضيف التعرّف على القطاع تلقائياً
> بعد نجاح الربط، لأن الاسم يأتي من تيليجرام نفسه.

## ٢) معرّف القناة — الرقم الذي تراه ليس ما يحتاجه الـ API

| ما تراه في تيليجرام | ما يحتاجه الـ API |
|---|---|
| `6444047765` | `-1006444047765` |

**لا داعي للحساب** — البوت يضيف `-100` تلقائياً إن نسيت.

### ثلاث طرق مقبولة للربط

| المُدخل | مثال | متى تستخدمه |
|---|---|---|
| معرّف رقمي | `-1001234567890` أو `1234567890` | الأسرع والأضمن |
| اسم المستخدم | `@my_channel` | إن كان للقناة يوزرنيم عام |
| رابط دعوة | `t.me/+abc123` | للقنوات الخاصة (البوت يجب أن يكون عضواً) |

## ٤) قاعدة الأولوية — «الأخصّ يفوز»

| الاسم | القطاع | لماذا |
|---|---|---|
| «أخبار الأنمي» | 🎌 أنمي | «أنمي» أخصّ من «أخبار» |
| «أخبار الرياضة» | ⚽ رياضة | نفس المنطق |
| «أخبار الوتين» | 📰 أخبار عامة | لا كلمة قطاعية |
| «قناة دجلة» | 🤷 لا شيء | لا دلالة → تبقى تستقبل كل شيء |

> **القاعدة الذهبية:** إذا لم نستطع تحديد الاختصاص، لا نربط القناة بمصادر عامة. تبقى بلا مصادر
> حتى تضيف وصفاً أو تختار قطاعاً؛ هذا يمنع تسرب الأخبار غير المناسبة.

## ٥) كيف تُختار المصادر؟ (ثلاث قواعد)

| القاعدة | التفصيل |
|---|---|
| **١ · التطابق الأفضل** | مصدر «تقنية + علوم» أفضل من «علوم» وحده (الزلازل ليست خبراً تقنياً) |
| **٢ · البحث متعدد اللغات** | نضيف اليابانية للأنمي/المانغا، والكورية للمانهوا، والصينية للمانهوا الصينية، مع التعريب إلى العربية |
| **٣ · عزل الاختصاص** | لا مصدر مطابق ← لا توجيه؛ تُنشأ خلاصات مخصصة قبل التفعيل |

### النتيجة على مشروعك الآن

| القناة | الوسوم | المصادر |
|---|---|---|
| `tg_main` الأخبار العامة | — | **٣٩ مصدراً** (كل الأخبار) |
| `tg_anime` الأنمي | أنمي · مانغا | ٤ مصادر (`myanimelist_news` · `gnews_anime_ar` …) |
| `tg_sports` الرياضة | رياضة · كرة | ٢ (`gnews_sports_iq` · `gnews_sports_world`) |
| `tg_tech` التقنية | تقنية · علوم | ٤ (`bbc_tech_ar` · `aitnews` · `techwd` …) |
| `tg_econ` الاقتصاد | اقتصاد · أسعار | ١ (`gnews_econ_iq`) |
| `tg_games` الألعاب | ألعاب · قيمنق | ١ (`gnews_games`) |
| `tg_local` المحافظات | محافظات · خدمات | ٢ (`ina_official` · `gnews_weather_iq`) |

> 🔧 **قرار تصميمي مهم:** القناة العامة تستخدم `*` فقط إذا كان ذلك اختياراً صريحاً في إعدادها.
> الفصل يحدث بالوسوم
> (`exclude_tags: [أنمي]` في `tg_main`) لا بحجب المصادر، وإلا صمتت الرئيسية
> وهذا يخالف شرط السرعة.

## ٧) من الطرفية (اختياري)

```bash
python -m autonews.sector_main --list                       # كل القطاعات
python -m autonews.sector_main --guess "أخبار الأنمي"        # ماذا سيتعرّف؟
python -m autonews.sector_main --apply tg_anime "أخبار الأنمي"  # طبّق فعلياً
```

مثال المخرجات:

```
🔍 الاسم: أخبار الأنمي والمانغا
   الاحتمالات: 🎌 أنمي ومانغا(9) · 📰 أخبار عامة(6)

✅ القطاع: 🎌 أنمي ومانغا
   الوسوم   : أنمي, مانغا
   المصادر  : 4 (4 مصدراً بهذه الوسوم)
            myanimelist_news, gnews_anime_ar, animecorner, gnews_anime_new
```

## ٨) تسمية قناتك — نصائح عملية

| الاسم | النتيجة |
|---|---|
| ✅ «أخبار الأنمي والمانغا» | 🎌 أنمي مباشرة |
| ✅ «عالم التقنية» | 💻 تقنية |
| ✅ «اقتصاد وأسعار الدولار» | 💵 اقتصاد |
| ⚠️ «قناة دجلة» | لا دلالة — كل شيء |
| ❌ «Anime» بالإنجليزي وحده | مدعوم (`anime`/`manga`) لكن العربية أوضح |

**قاعدة:** ضع كلمة القطاع في الاسم. «أخبار» وحدها = عام.

## ٩) هل يمكن التعديل بعد ذلك؟

نعم، من البوت: `🏷 عدّل الوسوم` — يضيف/يحذف وسوماً يدوياً.

والوسوم لا تحجب الأخبار: قناة لها وسم «أنمي» تستقبل كل خبر موسوم «أنمي»
**حتى لو** جاء من مصدر عام.

# 📋 إدارة القنوات من تيليجرام — دليل عملي

> كل ما هنا يُنفَّذ من هاتفك بضغطات. لا تحرير ملفات، ولا معرّف لكل قناة، ولا سرّ جديد.

---

## ١) لوحة القنوات وإدارتها

من الرسالة الرئيسية للبوت اضغط **«📋 القنوات وإدارتها»**:

```
📋 القنوات (عدد القنوات يتغيّر حسب ما تضيفه)

✅ 📰 القناة الرئيسية — أخبار عاجلة · أخبار عامة · 4/تشغيل
✅ 🎌 قناة الأنمي · أنمي ومانغا · 3/تشغيل
✅ ⚽ قناة الرياضة · رياضة · 4/تشغيل
...

اضغط أي قناة لإدارتها.
```

اضغط أي قناة تظهر شاشة تفاصيلها:

```
قناة الأنمي
tg_anime

الحالة: ✅ مفعّلة
الاختصاص: 🎌 أنمي ومانغا
عدد المنشورات/تشغيل: 3
الربط: ⬜ لم تُربط — اضغط «ربط بالاسم»
الوسوم: أنمي, مانغا
المصادر: 4
```

ومنها: **تعطيل/تفعيل · ✏️ الاختصاص · 🔢 عدد المنشورات · 📜 آخر المنشورات**.

## ٢) ➕ إضافة قناة جديدة — بالاسم والوصف فقط

اضغط **«➕ قناة جديدة»** ثم أرسل سطراً واحداً:

```
قناة الصحة والطب — كل ما يخص الطب والصحة والأدوية
```

فيحدث تلقائياً:

| ما يحدث | لماذا يهمّك |
|---|---|
| توليد المعرّف `tg_health` | لا تكتب معرّفات إنجليزية |
| استنتاج الاختصاص `🩺 صحة وطب` | من الاسم والوصف، بلا أسئلة |
| ضبط الوسوم `صحة, طب, علوم` | توجيه الأخبار الصحيحة |
| إضافة مصادر Google News للصحة | لا قناة صامتة |
| **بلا سرّ ولا معرّف لكل قناة** | الربط يُحفظ في المستودع الخاص |

اسم مبهم؟ تُضاف القناة بلا مصادر عامة ولا تستقبل أخباراً عشوائية. أرسل وصفاً أو اختر اختصاصاً حتى تُنشأ لها خلاصات مناسبة.
نفس الاختصاص لقناتين؟ يصلك **تنبيه** — الخلط لا يكون صامتاً.

> الصيغة القديمة `tg_crypto | قناة العملات | عملات, بيتكوين` **ما زالت تعمل**.

## ٣) ✏️ تغيير الاختصاص يدوياً

«✏️ الاختصاص» ← القطاعات الجاهزة أو ملف اختصاص مخصص ← اضغط:

```
💻 صار اختصاص القناة: تقنية
• كان: ⚽ رياضة
• الوسوم: تقنية, علوم, اتصالات
• المصادر: 5
```

الوسوم **والمصادر تتبدّل معاً** — لا تختلط أخبار الرياضة بأخبار التقنية.

---

## 🌏 اللغات حسب الاختصاص

- الأنمي والمانغا: العربية والإنجليزية واليابانية.
- المانهوا الكورية والويبتون: العربية والإنجليزية والكورية.
- المانهوا الصينية: العربية والإنجليزية والصينية.

تُترجم المواد إلى العربية قبل تجهيز المنشور. وتبقى القناة معزولة إذا لم يُنشأ لها مصدر يحمل وسم اختصاصها.

## ٤) 🔢 عدد المنشورات

«🔢 عدد المنشورات» ← أرسل رقماً (`٧` بالعربية مقبول):

```
✅ 💻 التقنية: 7 منشوراً كحدّ أقصى
```

`0` = بلا حدّ. القيمة العالية تستهلك توكنات أكثر.

## ٦) أين تُحفظ كل هذه التغييرات؟

| الملف | يحتوي |
|---|---|
| `config/channels.yml` | القنوات · الاختصاصات · الوسوم · عدد المنشورات · المصادر |
| `state/channels_setup.json` | الربط `@اسم_القناة` ← chat_id (بلا أسرار) |
| `state/control.json` | تعطيل/تفعيل · عدّاد المنشورات |

كلها داخل **المستودع الخاص `autonews-state`**: يُستعاد في بداية كل تشغيل ويُحفظ في نهايته.
أضفت قناة من هاتفك في التشغيل #١ → تجدها في التشغيل #٢ بلا خطوة إضافية.

**إثبات فعلي (دفعة git حقيقية إلى مستودع خاص محلي):**

```
① التشغيل #١ — أضاف: tg_economy | وسوم: ['اقتصاد','دولار','أسعار'] | مصادر: ['gnews_econ_iq']
② حُفظت في المستودع الخاص بدفعة git حقيقية ✅
③ التشغيل #٢ (بيئة جديدة) — القناة موجودة: True
   الوسوم والمصادر والتفعيل نفسه · 11 قناة مستعادة → لا فقدان للبيانات ✅
```
